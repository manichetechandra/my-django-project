## ما هي CSS؟

**CSS** تحدّد شكل العناصر: ألوانها، خطوطها، مسافاتها، مكانها في الصفحة. تتكوّن من **قواعد**، وكل قاعدة لها **محدِّد** (أيّ العناصر؟) ثم بين قوسين معقوفين `{ }` **خصائص** (كيف تبدو؟) بالشكل `الخاصية: القيمة;`:

```css مثال
h1 {
    color: #2c3e50;           /* لون النص */
    font-size: 32px;          /* حجم الخط */
}

.card {
    background: #ffffff;      /* لون الخلفية */
    border-radius: 10px;      /* زوايا دائرية */
    padding: 20px;            /* مسافة داخلية */
    margin-bottom: 30px;      /* مسافة خارجية من الأسفل */
    box-shadow: 0 5px 15px rgba(0, 0, 0, 0.1);   /* ظل */
}

.card:hover {
    transform: translateY(-5px);   /* ترتفع البطاقة قليلاً عند مرور الفأرة */
}
```

ما بين `/*` و`*/` **تعليق** لا يؤثر على شيء.

### أين نكتب CSS؟

1. داخل وسم `<style>` في الصفحة نفسها (هذا ما يفعله موقعنا، وسنفعله الآن).
2. في ملف منفصل `.css` نربطه بالوسم `<link rel="stylesheet" href="...">` (هكذا نستعمل Bootstrap، وملف `admin.css` في لوحة المدير لاحقاً).
3. مباشرة على العنصر بالخاصية `style`: `<p style="color: red;">` (للحالات الصغيرة فقط).

### المحدِّدات الأساسية

| المحدِّد | يختار | مثال |
|---|---|---|
| `p` | كل وسوم `<p>` | `p { line-height: 1.8; }` |
| `.card` | كل عنصر له `class="card"` | `.card { padding: 20px; }` |
| `#main` | العنصر الذي `id="main"` | `#main { width: 80%; }` |
| `.card img` | الصور الموجودة **داخل** `.card` (في أي عمق) | `.card img { width: 100%; }` |
| `ul > li` | عناصر `li` التي هي أبناء **مباشرون** لـ `ul` | `ul > li { float: right; }` |
| `.btn:hover` | الزر عند مرور الفأرة فوقه | `.btn:hover { opacity: .8; }` |
| `a, button` | الروابط **والأزرار** معاً (الفاصلة تجمع محدِّدات) | `a, button { cursor: pointer; }` |
| `*` | كل العناصر | `* { direction: rtl; }` |

إذا انطبقت قاعدتان على نفس العنصر بخصائص متعارضة، تفوز الأدقّ (`#id` أدقّ من `.class`، و`.class` أدقّ من اسم الوسم)، وعند التساوي تفوز القاعدة المكتوبة **أخيراً**. والكلمة `!important` بعد القيمة تجعلها تفوز على كل شيء.

### نموذج الصندوق (Box Model)

كل عنصر في الصفحة صندوق مكوّن من طبقات: **المحتوى** في الوسط، ثم **padding** (حشوة داخلية)، ثم **border** (الإطار)، ثم **margin** (هامش خارجي يبعده عن جيرانه). عندما تكتب `padding: 10px 20px` فالقيمة الأولى للأعلى والأسفل والثانية لليمين واليسار، و`margin: 0 auto` تعني صفراً للأعلى والأسفل وتوسيطاً أفقياً.

### الوحدات والألوان

- `px` بكسل ثابت، `%` نسبة من العنصر الأب، `em` نسبة من حجم الخط، `vh` نسبة من ارتفاع الشاشة.
- الألوان: بالاسم `white`، أو بالنظام الست عشري `#2c3e50` (لون موقعنا الأساسي الكحلي) و`#8cc040` (اللون الأخضر المميز)، أو مع شفافية `rgba(0, 0, 0, .5)` (أسود بنصف شفافية).

## Bootstrap 3: مكتبة تصميم جاهزة

بدل أن نصمّم كل زر وقائمة وعمود من الصفر نستعمل **Bootstrap**: ملف CSS (وملف JavaScript) فيه مئات الأصناف الجاهزة. يكفي أن نضيف الصنف المناسب للعنصر: `class="btn btn-success"` فيصبح الرابط زراً أخضر. يستعمل موقعنا الإصدار **3.4.1**، ونضمّنه من الإنترنت عبر **CDN** (شبكة خوادم تقدّم الملفات الشائعة بسرعة) فلا نحتاج تنزيله.

ومعه مكتبة **Font Awesome 4.7** التي توفّر أكثر من 600 أيقونة على شكل خط: نكتب `<i class="fa fa-home"></i>` فتظهر أيقونة البيت. قائمة كل الأيقونات وأسمائها على موقع `fontawesome.com/v4/icons`.

::: warning انسخ البصمات كما هي
البصمة طويلة ومرتبطة بإصدار الملف بالضبط. إن أخطأت في حرف منها، أو غيّرت رقم الإصدار في الرابط دون تغيير البصمة، سيرفض المتصفح الملف وتظهر الصفحة بلا تنسيق. عندها افتح أدوات المطوّر (F12) ← **Console**: ستجد رسالة تقول إن البصمة لا تطابق.
:::

لا يوجد Bootstrap 3 «عربي» رسمي: المكتبة مصمَّمة للغات التي تُكتب من اليسار إلى اليمين. سنقلبها بأنفسنا بقواعد CSS قليلة بعد قليل، بطريقة تعمل للعربية والفرنسية والإنجليزية معاً.

## التنسيقات العامة للموقع

### صفحة واحدة لثلاث لغات: الخصائص المنطقية

سيكون موقعنا بثلاث لغات: **العربية** (اللغة الأساسية) تُكتب من اليمين إلى اليسار، و**الفرنسية** و**الإنجليزية** من اليسار إلى اليمين. اتجاه الصفحة كلها تحدّده الخاصية `dir` في الوسم `<html>`: الآن `dir="rtl"`، وفي الصفحات الفرنسية سيصبح `dir="ltr"` (الفصل 18). فكيف نكتب CSS واحداً يناسب الاتجاهين؟

لو كتبنا `margin-right: 5px` لبقي الهامش على اليمين في كل اللغات. لذلك تعطينا CSS الحديثة **خصائص منطقية** لا تقول «يمين» و«يسار»، بل «**بداية** السطر» و«**نهايته**»، والمتصفح يترجمها حسب اتجاه الصفحة:

| خاصية منطقية | في صفحة عربية (`rtl`) | في صفحة فرنسية (`ltr`) |
|---|---|---|
| `text-align: start` | محاذاة لليمين | محاذاة لليسار |
| `text-align: end` | لليسار | لليمين |
| `margin-inline-start` | الهامش الأيمن | الهامش الأيسر |
| `margin-inline-end` / `padding-inline-end` | الأيسر | الأيمن |
| `float: inline-start` | يطفو إلى اليمين | يطفو إلى اليسار |
| `inset-inline-start: 0` | `right: 0` | `left: 0` |

سنكتب CSS الموقع كله بهذه الطريقة، فيعمل بالفرنسية والإنجليزية دون سطر إضافي.
