# أساسيات لغة PHP

::: intro
**PHP** هي اللغة التي سيُكتب بها «عقل» الموقع: استقبال الطلبات، التحقق من البيانات، التعامل مع قاعدة البيانات، تسجيل الدخول، رفع الملفات، وإنتاج صفحات HTML. في هذا الفصل نتعلّم كل ما يلزمنا من اللغة، وكل مثال هنا ستراه لاحقاً داخل المشروع. جرّب الأمثلة في الملف `C:\xampp\htdocs\test\index.php` وافتحه في المتصفح.
:::

## كيف يُكتب كود PHP؟

كود PHP يُكتب بين `<?php` و`?>`، ويمكن خلطه مع HTML في الملف نفسه:

```php
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<body>
    <h1><?php echo "مرحباً"; ?></h1>
    <p>السنة الحالية: <?= date('Y') ?></p>
</body>
</html>
```

- `<?= ... ?>` اختصار لـ `<?php echo ... ?>`. سنستعمله في كل القوالب.
- كل تعليمة تنتهي بفاصلة منقوطة `;`.
- إن كان الملف كله PHP (بدون HTML) نكتب `<?php` في أوله **ولا نغلقه** بـ `?>` في آخره، لتجنّب إرسال مسافات أو أسطر فارغة بالخطأ إلى المتصفح.

### التعليقات

```php
<?php
// تعليق في سطر واحد

/* تعليق
   في عدة أسطر */

/**
 * تعليق توثيقي يوضع فوق الدوال والأصناف ليشرح عملها
 */
```

التعليقات لا يُنفّذها PHP، وهي لك ولمن سيقرأ الكود بعدك. ستجد مشروعنا مليئاً بها بالعربية.

## المتغيرات وأنواع البيانات

يبدأ اسم المتغير دائماً بعلامة الدولار `$`:

```php
<?php
$title     = 'افتتاح المكتبة الجديدة';  // نص (string)
$views     = 150;                       // عدد صحيح (int)
$price     = 1200.50;                   // عدد عشري (float)
$is_active = true;                      // منطقي (bool): true أو false
$image     = null;                      // «لا شيء» (null)

var_dump($views);   // يعرض النوع والقيمة: int(150) — مفيد جداً لاكتشاف الأخطاء
```

::: note
أسماء المتغيرات **حسّاسة لحالة الأحرف**: `$Title` و`$title` متغيران مختلفان. أما أسماء الدوال فلا.
:::

### النصوص (Strings)

```php
<?php
$name = 'أحمد';
echo 'مرحباً ' . $name;        // الربط بالنقطة: مرحباً أحمد
echo "مرحباً $name";           // داخل علامتي التنصيص المزدوجتين تُستبدل المتغيرات
echo 'مرحباً $name';           // داخل المفردتين لا تُستبدل: تطبع $name حرفياً

$html = '<p>';
$html .= 'نص';                 // .= تضيف إلى آخر النص
$html .= '</p>';
```

أشهر دوال النصوص:

| الدالة | عملها | مثال ونتيجته |
|---|---|---|
| `trim($s)` | حذف المسافات من الطرفين | `trim('  أ  ')` ← `'أ'` |
| `mb_strlen($s)` | طول النص بالأحرف (يدعم العربية) | `mb_strlen('سطيف')` ← `4` |
| `mb_substr($s, $start, $len)` | جزء من النص | `mb_substr('سطيف', 0, 2)` ← `'سط'` |
| `str_replace($a, $b, $s)` | استبدال | `str_replace('-', ' ', 'a-b')` ← `'a b'` |
| `explode($sep, $s)` | تقطيع نص إلى مصفوفة | `explode(',', 'a,b')` ← `['a','b']` |
| `implode($sep, $arr)` | ربط مصفوفة في نص | `implode(', ', ['a','b'])` ← `'a, b'` |
| `strtolower($s)` | أحرف صغيرة | `strtolower('PDF')` ← `'pdf'` |
| `strpos($s, $x)` | موقع نص داخل آخر أو `false` | `strpos('abc', 'c')` ← `2` |
| `str_starts_with($s, $x)` | هل يبدأ بـ...؟ (PHP 8) | `str_starts_with('/admin/x', '/admin')` ← `true` |
| `sprintf($fmt, ...)` | نص بقالب | `sprintf('%05d', 42)` ← `'00042'` |
| `number_format($n, $d)` | تنسيق الأرقام | `number_format(1234.5, 1)` ← `'1,234.5'` |

::: warning
الدوال العادية مثل `strlen` و`substr` تعدّ **البايتات** لا الأحرف، والحرف العربي يأخذ بايتين في UTF-8، فيصبح `strlen('سطيف')` يساوي 8! لهذا نستعمل دائماً نسخ `mb_` مع النصوص العربية.
:::

## المصفوفات (Arrays)

المصفوفة متغير يحمل عدة قيم. وهي أهم بنية في PHP، وكل صف يأتي من قاعدة البيانات يصلنا مصفوفة.

```php
<?php
// مصفوفة مرقّمة (الفهارس 0، 1، 2...)
$cities = ['سطيف', 'العلمة', 'عين ولمان'];
echo $cities[0];               // سطيف
$cities[] = 'بوقاعة';          // إضافة عنصر في الآخر
echo count($cities);           // 4

// مصفوفة ترابطية (مفتاح => قيمة)
$news = [
    'id'    => 7,
    'title' => 'افتتاح المكتبة',
    'views' => 150,
];
echo $news['title'];

// مصفوفة متداخلة: قائمة أخبار
$all = [
    ['id' => 1, 'title' => 'خبر أول'],
    ['id' => 2, 'title' => 'خبر ثانٍ'],
];
echo $all[1]['title'];         // خبر ثانٍ

// تفكيك مصفوفة إلى متغيرات
[$first, $second] = ['أ', 'ب'];
```

أشهر دوال المصفوفات:

| الدالة | عملها |
|---|---|
| `count($a)` | عدد العناصر |
| `in_array($x, $a)` | هل القيمة موجودة؟ |
| `array_key_exists($k, $a)` | هل المفتاح موجود؟ |
| `array_keys($a)` / `array_values($a)` | المفاتيح / القيم فقط |
| `array_merge($a, $b)` | دمج مصفوفتين |
| `array_slice($a, $start, $len)` | جزء من المصفوفة |
| `array_map($fn, $a)` | تطبيق دالة على كل عنصر وإرجاع مصفوفة جديدة |
| `array_filter($a, $fn)` | الإبقاء على العناصر التي تحقق شرطاً |
| `array_pad($a, $n, $v)` | تكملة المصفوفة إلى طول معيّن |

### isset وempty والعامل ??

```php
<?php
isset($news['image']);          // true إذا كان المفتاح موجوداً وقيمته ليست null
empty($news['image']);          // true إذا كان غير موجود أو فارغاً ('' أو 0 أو null أو [])

$page = $_GET['page'] ?? 1;     // إن لم يوجد page في العنوان فالقيمة 1
```

العامل `??` («القيمة أو البديل») سنستعمله في كل مكان تقريباً لأنه يمنع أخطاء «مفتاح غير موجود».

## العوامل (Operators)

| النوع | العوامل |
|---|---|
| حسابية | `+` `-` `*` `/` `%` (باقي القسمة) `**` (أس)، `intdiv()` قسمة صحيحة |
| زيادة ونقصان | `$i++` `$i--`، و`$x += 5` |
| مقارنة | `==` (يساوي بعد التحويل)، `===` (يساوي **وبنفس النوع**)، `!=` `!==` `<` `>` `<=` `>=` |
| منطقية | `&&` (و)، `\|\|` (أو)، `!` (نفي) |
| الشرط المختصر | `$x ? 'نعم' : 'لا'`، و`$x ?: 'بديل'` |

::: tip
استعمل `===` دائماً تقريباً. فالمقارنة `0 == 'abc'` كانت تعطي `true` في الإصدارات القديمة! و`===` تمنع هذه المفاجآت.
:::

## الحلقات

```php
<?php
// المرور على كل عناصر مصفوفة
foreach ($cities as $city) {
    echo $city . '<br>';
}

// مع المفتاح
```

## الدوال (Functions)

الدالة مجموعة تعليمات لها اسم، نكتبها مرة ونستدعيها متى شئنا:

```php
<?php
function greet(string $name, string $greeting = 'مرحباً'): string
{
    return $greeting . ' ' . $name;
}

echo greet('أحمد');              // مرحباً أحمد
echo greet('سارة', 'أهلاً');     // أهلاً سارة
```

- `string $name`: **نوع** المعامل (int، string، bool، array، float، أو اسم صنف). إن مرّرت نوعاً خاطئاً يظهر خطأ واضح.
- `$greeting = 'مرحباً'`: قيمة **افتراضية** تُستعمل إذا لم يُمرَّر المعامل.
- `: string` بعد القوسين: نوع **القيمة المُرجَعة**. و`: void` تعني أن الدالة لا تُرجع شيئاً.
- `?string`: النوع «نص **أو** null».

### أنواع خاصة من الدوال والمعاملات

```php
<?php
// عدد غير محدد من المعاملات: كلها تُجمع في مصفوفة $params
function url(string $name, ...$params): string { /* ... */ }
url('news:news_detail', 'my-slug');

// تمرير بالمرجع &: الدالة تعدّل المتغير الأصلي نفسه
function addParam(array &$params, $value): void { $params[] = $value; }

// متغير static: يحتفظ بقيمته بين الاستدعاءات (نستعمله للتخزين المؤقت)
function counter(): int
{
    static $n = 0;
    return ++$n;
}

// دالة مجهولة (بلا اسم) تُخزّن في متغير، وuse تُدخل متغيراً من الخارج
$prefix = 'سطيف';
$fn = function ($x) use ($prefix) { return $prefix . ' ' . $x; };

// الدالة السهمية المختصرة fn: ترى المتغيرات الخارجية تلقائياً
$doubled = array_map(fn($n) => $n * 2, [1, 2, 3]);   // [2, 4, 6]

// استدعاء دالة من اسمها المخزّن في نص (هكذا يعمل الموجّه في مشروعنا)
$handler = 'greet';
echo $handler('أحمد');
```

## تقسيم الكود على عدة ملفات

```php
<?php
require __DIR__ . '/functions.php';        // تضمين ملف (خطأ قاتل إن لم يوجد)
require_once __DIR__ . '/functions.php';   // نفسه لكن لا يُضمَّن مرتين
include __DIR__ . '/sidebar.php';          // تضمين (تحذير فقط إن لم يوجد)

$config = require __DIR__ . '/config.php'; // الملف المضمَّن يمكنه إرجاع قيمة بـ return
```

`__DIR__` ثابت سحري يحمل مسار المجلد الذي فيه الملف الحالي، فيعمل المسار مهما كان المجلد الذي شُغّل منه السكربت.

### الثوابت

```php
<?php
define('BASE_PATH', __DIR__);      // ثابت قيمته لا تتغير، ويُستعمل بلا $
const AR_DAYS = ['الأحد', 'الإثنين'];
echo BASE_PATH;
```

## المتغيرات العامة الجاهزة (Superglobals)

مصفوفات يملؤها PHP تلقائياً في كل طلب، ومتاحة في كل مكان:

| المتغير | محتواه |
|---|---|
| `$_GET` | معاملات العنوان: في `/search/?q=منحة` يكون `$_GET['q']` = `'منحة'` |
| `$_POST` | حقول النموذج المرسَل بطريقة POST |
| `$_FILES` | الملفات المرفوعة: الاسم، النوع، المسار المؤقت، الحجم، رمز الخطأ |
| `$_SERVER` | معلومات الطلب: `REQUEST_METHOD`، `REQUEST_URI`، `REMOTE_ADDR` (عنوان IP)... |
| `$_SESSION` | بيانات تبقى محفوظة للمستخدم بين الصفحات (بعد `session_start()`) |
| `$_COOKIE` | الكوكيز التي يرسلها المتصفح |
| `$GLOBALS` | كل المتغيرات العامة |

::: warning
كل ما يأتي من `$_GET` و`$_POST` و`$_FILES` و`$_COOKIE` يتحكّم فيه الزائر، وقد يكون خبيثاً. **لا تثق به أبداً**: تحقّق منه، وهرّبه قبل عرضه، ولا تضعه مباشرة داخل استعلام SQL. سنطبّق هذه القاعدة في كل المشروع.
:::

## الجلسات (Sessions)

بروتوكول HTTP «بلا ذاكرة»: كل طلب مستقل عن الذي قبله. فكيف يبقى الطالب مسجّلاً للدخول وهو يتنقل بين الصفحات؟ بـ**الجلسة**: يعطي PHP المتصفح رقماً سرياً في كوكي، ويحفظ في الخادم مصفوفة `$_SESSION` مرتبطة بهذا الرقم.

```php
<?php
session_start();                       // يجب استدعاؤها قبل أي إخراج
$_SESSION['user_id'] = 5;              // في صفحة تسجيل الدخول
echo $_SESSION['user_id'] ?? 'زائر';   // في أي صفحة أخرى
unset($_SESSION['user_id']);           // تسجيل الخروج
```

## الترويسات وإعادة التوجيه

```php
<?php
header('Location: /students/dashboard/');   // أرسل المتصفح إلى صفحة أخرى
exit;                                        // وأوقف التنفيذ فوراً

http_response_code(404);                     // رمز الحالة: الصفحة غير موجودة
header('Content-Type: application/json; charset=utf-8');
echo json_encode(['ok' => true], JSON_UNESCAPED_UNICODE);   // رد بصيغة JSON
```

::: warning
الترويسات تُرسَل قبل محتوى الصفحة، لذا يجب استدعاء `header()` و`session_start()` **قبل أي** `echo` أو HTML، وإلا ظهر الخطأ الشهير: `Cannot modify header information - headers already sent`.
:::

## البرمجة الكائنية (OOP)

**الصنف** (class) قالب يصف نوعاً من الأشياء: بياناته (**خصائص**) وما يستطيع فعله (**دوال** أو methods). و**الكائن** (object) نسخة حقيقية من هذا القالب.

```php
<?php
class Student
{
    public string $name;               // خاصية عامة
    private string $password = '';     // خاصية خاصة: لا تُقرأ من خارج الصنف
    public static int $count = 0;      // خاصية «ثابتة» مشتركة بين كل الكائنات

    public function __construct(string $name)   // تُنفَّذ تلقائياً عند new
    {
        $this->name = $name;           // $this = الكائن الحالي
        self::$count++;
    }

    public function greet(): string
    {
        return 'مرحباً ' . $this->name;
    }

    public static function total(): int          // دالة ثابتة: تُستدعى بلا كائن
    {
        return self::$count;
    }
}

$s = new Student('أحمد');      // إنشاء كائن
echo $s->greet();              // استدعاء دالة بالسهم ->
echo $s->name;
echo Student::total();         // دالة ثابتة بالعامل ::
```

| الكلمة | معناها |
|---|---|
| `public` / `protected` / `private` | متاح للجميع / للصنف وأبنائه / للصنف وحده |
| `static` | ينتمي للصنف نفسه لا لكائن بعينه، ويُستدعى بـ `::` |
| `self::` | الصنف الذي كُتب فيه الكود |
| `static::` | الصنف الذي استُدعيت منه الدالة فعلاً (مهم في الوراثة) |
| `Student::class` | اسم الصنف كنص: `'Student'` |

### الوراثة والأصناف المجرّدة

```php
<?php
abstract class Model                 // صنف «مجرّد»: لا يُنشأ منه كائن مباشرة
{
    protected static string $table = '';

    public static function table(): string
    {
        return static::$table;       // static:: تقرأ قيمة الصنف الابن
    }
}

class News extends Model             // News يرث كل ما في Model
{
    protected static string $table = 'news';
}

echo News::table();                  // news
```

هذه هي الفكرة التي يقوم عليها صنف `Model` في مشروعنا: نكتب كود القراءة والحفظ مرة واحدة في الصنف الأب، ويكفي كل صنف ابن أن يحدّد اسم جدوله. الكلمة `final` تمنع وراثة صنف أو إعادة كتابة دالة.

### الواجهات والدوال السحرية

**الواجهة** (interface) عقد: الصنف الذي «يطبّقها» (`implements`) يَعِد بكتابة دوال معيّنة. مثلاً الواجهة الجاهزة `ArrayAccess` تسمح بقراءة الكائن كأنه مصفوفة `$news['title']`، و`Countable` تسمح بـ `count($obj)`، و`IteratorAggregate` تسمح بالمرور عليه بـ `foreach`.

و**الدوال السحرية** تبدأ بشرطتين سفليتين ويستدعيها PHP تلقائياً:

| الدالة | متى تُستدعى |
|---|---|
| `__construct()` | عند إنشاء الكائن بـ `new` |
| `__get($name)` | عند قراءة خاصية غير موجودة: `$obj->title` |
| `__set($name, $value)` | عند الكتابة في خاصية غير موجودة |
| `__call($name, $args)` | عند استدعاء دالة غير موجودة: `$obj->get_status_display()` |
| `__toString()` | عند استعمال الكائن كنص: `echo $obj` |

و`$x instanceof News` تسأل: هل هذا الكائن من صنف News (أو أحد أبنائه)؟

## الاستثناءات (Exceptions)

عندما يحدث خطأ غير متوقّع «يُرمى» استثناء يوقف التنفيذ، ويمكننا «التقاطه» ومعالجته:

```php
<?php
class HttpException extends Exception {}     // صنف استثناء خاص بنا

try {
    if (!$news) {
        throw new HttpException('الخبر غير موجود', 404);   // رمي
    }
} catch (HttpException $e) {                  // التقاط
    echo 'خطأ ' . $e->getCode() . ': ' . $e->getMessage();
} finally {
    // يُنفَّذ دائماً سواء حدث خطأ أم لا
}
```

## صيغة القوالب البديلة

داخل ملفات HTML تصبح الأقواس `{ }` صعبة القراءة، لذلك توفّر PHP **صيغة بديلة** تنتهي بكلمات واضحة. **كل قوالب مشروعنا مكتوبة بها**، فتعوّد عليها:

```php
<?php if ($news_list): ?>
    <ul>
    <?php foreach ($news_list as $news): ?>
        <li><?= e($news['title']) ?></li>
    <?php endforeach; ?>
    </ul>
<?php elseif ($show_message): ?>
    <p>لا توجد أخبار.</p>
<?php else: ?>
    <p>...</p>
<?php endif; ?>
```

لاحظ النقطتين `:` بعد الشرط بدل `{`، وكلمات الإغلاق `endif;` و`endforeach;` و`endfor;` و`endwhile;`.

## التخزين المؤقت للمخرجات (Output Buffering)

```php
<?php
ob_start();                  // ابدأ «التقاط» كل ما يُطبع بدل إرساله
echo '<p>نص</p>';
include 'template.php';      // حتى مخرجات القوالب تُلتقط
$html = ob_get_clean();      // خذ ما التُقط كنص وأوقف الالتقاط
```

بهذه الحيلة يستطيع صنف القوالب في مشروعنا تحويل قالب كامل إلى نص، ثم وضعه داخل القالب الرئيسي.

## التواريخ

```php
<?php
echo date('Y-m-d H:i:s');            // 2026-10-28 14:30:00 (الصيغة التي تحفظها MySQL)
echo date('d/m/Y', strtotime('+7 days'));   // التاريخ بعد أسبوع

$d = new DateTimeImmutable('2025-11-20 11:47:37');
echo $d->format('d/m/Y');            // 20/11/2025
```

أحرف الصيغة: `Y` السنة، `m` الشهر، `d` اليوم، `H` الساعة (0–23)، `i` الدقائق، `s` الثواني.

## التعابير النمطية (Regex) باختصار

التعبير النمطي نمط للبحث في النصوص. لا تحتاج إتقانه الآن، فقط تعرّف على الشكل:

```php
<?php
preg_match('/^\d+$/', '2023');                // هل النص أرقام فقط؟ ← 1 (نعم)
preg_match('#^/news/([^/]+)/$#', '/news/abc/', $m);   // $m[1] = 'abc'
preg_replace('/\s+/', '-', 'a  b c');         // 'a-b-c'
```

`^` بداية النص، `$` نهايته، `\d` رقم، `\s` مسافة، `+` مرة أو أكثر، `[^/]` أي حرف ما عدا `/`، والأقواس `( )` تلتقط الجزء المطابق.

## أوّل لمسة أمان: تهريب المخرجات

تخيّل أن زائراً كتب في خانة الاسم: `<script>alert('اختراق')</script>`. لو عرضناه كما هو بـ `echo` لنفّذ المتصفح الكود! هذا هجوم اسمه **XSS**. الحل: تحويل الرموز الخاصة إلى نص آمن:

```php
<?php
$name = "<script>alert('x')</script>";
echo htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
// &lt;script&gt;alert(&#039;x&#039;)&lt;/script&gt;  ← يظهر كنص عادي ولا يُنفَّذ
```

في مشروعنا سنكتب دالة قصيرة `e()` تفعل هذا، ونستعملها مع **كل** قيمة نعرضها: `<?= e($news['title']) ?>`.

::: summary
- المتغيرات تبدأ بـ `$`، والنصوص العربية تحتاج دوال `mb_`.
- المصفوفات الترابطية `['title' => ...]` هي الشكل الذي تصلنا به صفوف قاعدة البيانات.
- `??` تعطي قيمة بديلة، و`===` مقارنة دقيقة.
- الدوال بأنواع معاملات وقيم مُرجعة، و`...$params` و`static` و`fn`.
- الأصناف والوراثة و`static::` أساس صنف النماذج.
- القوالب تستعمل الصيغة البديلة `if: ... endif;` و`foreach: ... endforeach;`.
- لا نثق بمدخلات المستخدم، ونهرّب كل ما نعرضه.
:::
