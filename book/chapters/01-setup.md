# تجهيز بيئة العمل

::: intro
قبل أن نكتب أي سطر نحتاج «ورشة» على حاسوبنا: خادم ويب يشغّل PHP، وقاعدة بيانات MySQL، ومحرر نكتب فيه الكود. في هذا الفصل نثبّت كل ذلك خطوة بخطوة، ونكتب أول صفحة PHP ونراها في المتصفح.
:::

## لماذا نحتاج «خادماً محلياً»؟

صفحة HTML عادية يستطيع المتصفح فتحها مباشرة بالنقر المزدوج عليها. أما ملفات **PHP** فلا يفهمها المتصفح؛ يجب أن يمرّ الطلب أولاً على **خادم ويب** (Apache) يسلّم الملف إلى **مفسّر PHP**، فينفّذ الكود ويُرجع النتيجة (HTML) إلى المتصفح.

على الإنترنت يكون هذا الخادم حاسوباً في مركز بيانات. وأثناء التطوير نشغّل خادماً **على حاسوبنا نفسه**، ونصل إليه بالعنوان `localhost` الذي يعني «هذا الحاسوب».

## تثبيت XAMPP

**XAMPP** حزمة مجانية تجمع كل ما نحتاجه: **A**pache و**M**ySQL (في الحقيقة MariaDB، وهي نسخة متوافقة تماماً مع MySQL) و**P**HP و**P**erl، إضافة إلى أداة **phpMyAdmin** لإدارة قواعد البيانات من المتصفح.

1. ادخل إلى الموقع الرسمي `https://www.apachefriends.org` واختر **XAMPP for Windows**.
2. اختر نسخة فيها **PHP 8** أو أحدث (مشروعنا يتطلّب PHP 8.0 على الأقل).
3. شغّل الملف الذي نزّلته. إذا ظهرت رسالة عن برنامج الحماية أو عن **UAC** فاضغط **OK** وتابع.
4. في شاشة اختيار المكونات (Select Components) يكفي: **Apache** و**MySQL** و**PHP** و**phpMyAdmin**. يمكنك إلغاء الباقي.
5. اترك مجلد التثبيت كما هو: `C:\xampp`.

::: warning
لا تثبّت XAMPP داخل `C:\Program Files`؛ فقيود الصلاحيات في هذا المجلد تمنع Apache وMySQL من الكتابة في ملفاتهما وتسبّب أخطاء غريبة. المجلد `C:\xampp` هو الاختيار الصحيح.
:::

## تشغيل Apache وMySQL

افتح **XAMPP Control Panel** من قائمة ابدأ. ستجد سطراً لكل خدمة:

| الزر | وظيفته |
|---|---|
| **Start / Stop** | تشغيل الخدمة أو إيقافها |
| **Admin** | فتح صفحة إدارة الخدمة (لـ MySQL يفتح phpMyAdmin) |
| **Config** | فتح ملفات الإعداد مثل `httpd.conf` و`php.ini` |
| **Logs** | سجلات الأخطاء: أول مكان تبحث فيه عند حدوث مشكلة |

اضغط **Start** بجانب **Apache** ثم بجانب **MySQL**. عندما يصبح اسم الخدمة على خلفية **خضراء** وتظهر أرقام المنافذ (Ports) مثل `80, 443` و`3306` فكل شيء يعمل.

افتح المتصفح واكتب `http://localhost`. إن ظهرت صفحة ترحيب XAMPP فالتثبيت ناجح.

::: warning إذا لم يشتغل Apache
السبب الأشهر أن برنامجاً آخر يستعمل المنفذ 80 (مثل Skype القديم أو IIS أو برنامج VMware). الحلول:

- أغلق البرنامج المتعارض ثم أعد المحاولة.
- أو غيّر منفذ Apache: **Config ← httpd.conf**، ابحث عن `Listen 80` واجعلها `Listen 8080`، وابحث عن `ServerName localhost:80` واجعلها `ServerName localhost:8080`. بعدها تفتح المواقع بالعنوان `http://localhost:8080`.

ونفس الفكرة لـ MySQL إذا كان المنفذ 3306 مستعملاً من نسخة MySQL أخرى مثبّتة على الجهاز.
:::

## مجلد htdocs: أين نضع مواقعنا؟

كل ما تضعه داخل المجلد `C:\xampp\htdocs` يصبح متاحاً من المتصفح:

| الملف على القرص | العنوان في المتصفح |
|---|---|
| `C:\xampp\htdocs\index.php` | `http://localhost/` |
| `C:\xampp\htdocs\test\index.php` | `http://localhost/test/` |
| `C:\xampp\htdocs\dou-setif\index.php` | `http://localhost/dou-setif/` |

عندما يطلب المتصفح مجلداً (مثل `/test/`) يبحث Apache تلقائياً عن ملف اسمه `index.php` أو `index.html` داخله.

## إظهار امتدادات الملفات في Windows

يخفي Windows افتراضياً امتدادات الملفات، فقد تنشئ ملفاً تظنّه `index.php` وهو في الحقيقة `index.php.txt`. لتجنّب ذلك:
افتح مستكشف الملفات ← تبويب **عرض (View)** ← فعّل **ملحقات أسماء الملفات (File name extensions)**.

## تثبيت محرر الأكواد Visual Studio Code

1. نزّل **VS Code** من `https://code.visualstudio.com` وثبّته بالإعدادات الافتراضية. فعّل خيار **Add "Open with Code" action** ليظهر في القائمة عند النقر بالزر الأيمن.
2. افتحه، ثم من الشريط الجانبي الأيسر اضغط أيقونة **Extensions** (المربعات الأربعة) وثبّت الإضافة **PHP Intelephense**: تكمل لك أسماء الدوال وتكشف الأخطاء قبل التشغيل.
3. من **File ← Auto Save** فعّل الحفظ التلقائي حتى لا تنسى الحفظ قبل تحديث المتصفح.

::: note
تأكّد أن الترميز المكتوب في الشريط السفلي لـ VS Code هو **UTF-8** (وهو الافتراضي). هذا ضروري لتظهر الحروف العربية سليمة. إذا رأيت يوماً رموزاً غريبة مثل `Ø§Ù„` بدل العربية فالسبب غالباً ملف محفوظ بترميز آخر أو اتصال بقاعدة البيانات بترميز خاطئ.
:::

## أول صفحة PHP لك

1. أنشئ مجلداً جديداً: `C:\xampp\htdocs\test`.
2. افتحه في VS Code (**File ← Open Folder**).
3. أنشئ ملفاً جديداً اسمه `index.php` واكتب فيه:

```php C:\xampp\htdocs\test\index.php
<?php
echo "مرحباً بالعالم!";
echo "<br>";
echo "الساعة الآن: " . date('H:i');
```

4. افتح المتصفح على `http://localhost/test/`.

ستظهر لك الجملة والساعة. مبروك، هذه أول صفحة PHP تعمل على خادمك! لاحظ ما حدث:

- `<?php` تخبر الخادم أن ما بعدها كود PHP.
- `echo` تطبع نصاً في الصفحة.
- `date('H:i')` دالة جاهزة تُرجع الساعة والدقيقة الحاليتين.
- النقطة `.` تلصق نصّين معاً.
- كل تعليمة تنتهي بفاصلة منقوطة `;`.

::: try
اضغط **Ctrl+U** في المتصفح لترى «مصدر الصفحة». لن تجد أي كود PHP، بل النتيجة فقط: `مرحباً بالعالم!<br>الساعة الآن: ...`. هذا هو المبدأ الأساسي: **PHP يعمل على الخادم، والمتصفح لا يرى إلا الناتج**.
:::

## معرفة إصدار PHP وإضافاته

غيّر محتوى الملف السابق إلى:

```php C:\xampp\htdocs\test\index.php
<?php
phpinfo();
```

ستظهر صفحة طويلة فيها كل معلومات PHP. تأكّد من:

- **PHP Version**: يجب أن يكون 8.0 أو أكثر.
- وجود أقسام باسم **pdo_mysql** و**mbstring** (ضروريتان)، و**fileinfo** و**zip** (مفيدتان: الأولى لفحص نوع الملفات المرفوعة، والثانية لتصدير ملفات Excel).

## إعداد ملف php.ini

ملف إعدادات PHP هو `C:\xampp\php\php.ini`، وتفتحه أيضاً من لوحة XAMPP: **Apache ← Config ← PHP (php.ini)**. ابحث فيه (Ctrl+F) عن الأسطر التالية وتأكّد أنها **بدون فاصلة منقوطة في بدايتها** (الفاصلة المنقوطة `;` في هذا الملف تعني أن السطر معطّل):

```ini php.ini
extension=fileinfo
extension=mbstring
extension=pdo_mysql
extension=zip

upload_max_filesize = 40M
post_max_size = 40M
date.timezone = Africa/Algiers
```

`upload_max_filesize` و`post_max_size` يحددان أكبر حجم لملف مرفوع؛ نحتاجهما لأن الطلبة سيرفعون وثائقهم، والإدارة سترفع صوراً وملفات PDF.

::: warning
بعد أي تعديل على `php.ini` يجب **إيقاف Apache وتشغيله من جديد** (Stop ثم Start) حتى يقرأ الإعدادات الجديدة.
:::

## phpMyAdmin: إدارة قواعد البيانات من المتصفح

افتح `http://localhost/phpmyadmin` (أو اضغط **Admin** بجانب MySQL). هذه واجهة رسومية تسمح لك بإنشاء قواعد البيانات والجداول، وتنفيذ أوامر SQL، واستيراد الملفات وتصديرها. المستخدم الافتراضي في XAMPP هو `root` **بدون كلمة مرور**، ولهذا تدخل مباشرة. سنستعملها كثيراً في الفصلين 4 و6.

## سطر الأوامر

أحياناً نحتاج تشغيل سكربت PHP من **سطر الأوامر** بدل المتصفح (مثلاً لإنشاء حساب المدير). افتح قائمة ابدأ واكتب `cmd` ثم Enter، واكتب:

```cmd
C:\xampp\php\php.exe -v
```

يجب أن يظهر إصدار PHP. ولتنفيذ ملف:

```cmd
cd C:\xampp\htdocs\test
C:\xampp\php\php.exe index.php
```

::: tip
لتكتب `php` فقط بدل المسار الكامل أضف المجلد `C:\xampp\php` إلى متغير البيئة **PATH**: ابحث في قائمة ابدأ عن «تحرير متغيرات بيئة النظام» ← **Environment Variables** ← اختر **Path** ← **Edit** ← **New** ← اكتب `C:\xampp\php` ← OK. أغلق نافذة الأوامر وافتح واحدة جديدة.
:::

## أدوات المطوّر في المتصفح

في Chrome أو Firefox أو Edge اضغط **F12** لتفتح أدوات المطوّر، وأهم تبويباتها:

| التبويب | فائدته |
|---|---|
| **Elements** | رؤية عناصر HTML وتجربة تعديل CSS مباشرة |
| **Console** | رؤية أخطاء JavaScript وتجربة الأوامر |
| **Network** | رؤية كل الطلبات التي ترسلها الصفحة (الصور، CSS، طلبات AJAX) وحالتها مثل 200 أو 404 |

وزر **تبديل وضع الجهاز** (أيقونة الهاتف) يعرض الصفحة كما تظهر على الهاتف، وهو مفيد لاختبار التصميم المتجاوب.

## تجهيز مجلد المشروع

أخيراً أنشئ مجلد مشروعنا الذي سنعمل فيه طوال الكتاب:

```cmd
mkdir C:\xampp\htdocs\dou-setif
```

ثم افتحه في VS Code: **File ← Open Folder ← C:\xampp\htdocs\dou-setif**. من الآن، كل مسار يظهر في رأس صناديق الكود (مثل `app/core/DB.php`) هو مسار **داخل هذا المجلد**.

::: summary
- XAMPP يوفّر Apache (خادم الويب) وPHP وMySQL/MariaDB وphpMyAdmin.
- مواقعنا توضع في `C:\xampp\htdocs` وتُفتح عبر `http://localhost/...`.
- PHP يُنفَّذ على الخادم، والمتصفح لا يرى إلا الناتج.
- `php.ini` هو ملف إعدادات PHP، ونعيد تشغيل Apache بعد تعديله.
- مجلد مشروعنا: `C:\xampp\htdocs\dou-setif`.
:::
