# تجهيز بيئة العمل والمجلد الفارغ

::: intro
قبل أن نكتب أي سطر نحتاج «ورشة» على حاسوبنا: خادم ويب، ولغة PHP، وقاعدة بيانات MySQL، ومحرر نكتب فيه الكود. في هذا الفصل نثبّت كل ذلك خطوة بخطوة، وننتهي بإنشاء **مجلد المشروع الفارغ** الذي سنبني فيه الموقع كله.
:::

## لماذا نحتاج «خادماً محلياً»؟

صفحة HTML عادية يستطيع المتصفح فتحها مباشرة بالنقر المزدوج عليها. لكن موقعنا سيستعمل لاحقاً لغة **PHP** وقاعدة بيانات، والمتصفح لا يفهم PHP؛ يجب أن يمرّ الطلب أولاً على **خادم ويب** (Apache) يسلّم الملف إلى **مفسّر PHP**، فينفّذ الكود ويُرجع النتيجة (HTML) إلى المتصفح.

على الإنترنت يكون هذا الخادم حاسوباً في مركز بيانات. وأثناء التطوير نشغّل خادماً **على حاسوبنا نفسه**، ونصل إليه بالعنوان `localhost` الذي يعني «هذا الحاسوب».

<div class="flow">
  <div class="st"><b>المتصفح</b><small>http://localhost/dou-setif/</small></div><span class="ar">←</span>
  <div class="st"><b>Apache</b>يجد الملف<small>C:\xampp\htdocs\dou-setif</small></div><span class="ar">←</span>
  <div class="st hl"><b>PHP</b>ينفّذ الكود (إن وُجد)</div><span class="ar">←</span>
  <div class="st"><b>HTML</b>يعود إلى المتصفح</div>
</div>

لذلك سنفتح صفحاتنا من البداية عبر الخادم (`http://localhost/...`) لا بالنقر المزدوج، حتى نتعوّد على الطريقة الصحيحة.

## تثبيت XAMPP

**XAMPP** حزمة مجانية تجمع كل ما نحتاجه: **A**pache و**M**ySQL (في الحقيقة MariaDB، وهي نسخة متوافقة تماماً مع MySQL) و**P**HP و**P**erl، إضافة إلى أداة **phpMyAdmin** لإدارة قواعد البيانات من المتصفح.

1. ادخل إلى الموقع الرسمي `https://www.apachefriends.org` واختر **XAMPP for Windows**.
2. اختر نسخة فيها **PHP 8** أو أحدث (مشروعنا يتطلّب PHP 8.0 على الأقل).
3. شغّل الملف الذي نزّلته. إذا ظهرت رسالة عن برنامج الحماية أو عن **UAC** فاضغط **OK** وتابع.
4. في شاشة اختيار المكونات (Select Components) يكفي: **Apache** و**MySQL** و**PHP** و**phpMyAdmin**. يمكنك إلغاء الباقي.
5. اترك مجلد التثبيت كما هو: `C:\xampp`.

::: warning
لا تثبّت XAMPP داخل `C:\Program Files`؛ فقيود الصلاحيات في هذا المجلد تمنع Apache وMySQL من الكتابة في ملفاتهما وتسبّب أخطاء غريبة. المجلد `C:\xampp` هو الاختيار الصحيح.
:::

## تشغيل Apache وMySQL

افتح **XAMPP Control Panel** من قائمة ابدأ. ستجد سطراً لكل خدمة:

| الزر | وظيفته |
|---|---|
| **Start / Stop** | تشغيل الخدمة أو إيقافها |
| **Admin** | فتح صفحة إدارة الخدمة (لـ MySQL يفتح phpMyAdmin) |
| **Config** | فتح ملفات الإعداد مثل `httpd.conf` و`php.ini` |
| **Logs** | سجلات الأخطاء: أول مكان تبحث فيه عند حدوث مشكلة |

اضغط **Start** بجانب **Apache** ثم بجانب **MySQL**. عندما يصبح اسم الخدمة على خلفية **خضراء** وتظهر أرقام المنافذ (Ports) مثل `80, 443` و`3306` فكل شيء يعمل.

افتح المتصفح واكتب `http://localhost`. إن ظهرت صفحة ترحيب XAMPP فالتثبيت ناجح.

::: warning إذا لم يشتغل Apache
السبب الأشهر أن برنامجاً آخر يستعمل المنفذ 80 (مثل Skype القديم أو IIS أو برنامج VMware). الحلول:

- أغلق البرنامج المتعارض ثم أعد المحاولة.
- أو غيّر منفذ Apache: **Config ← httpd.conf**، ابحث عن `Listen 80` واجعلها `Listen 8080`، وابحث عن `ServerName localhost:80` واجعلها `ServerName localhost:8080`. بعدها تفتح المواقع بالعنوان `http://localhost:8080`.

ونفس الفكرة لـ MySQL إذا كان المنفذ 3306 مستعملاً من نسخة MySQL أخرى مثبّتة على الجهاز.
:::

## مجلد htdocs: أين نضع مواقعنا؟

كل ما تضعه داخل المجلد `C:\xampp\htdocs` يصبح متاحاً من المتصفح:

| الملف على القرص | العنوان في المتصفح |
|---|---|
| `C:\xampp\htdocs\index.html` | `http://localhost/` |
| `C:\xampp\htdocs\test\page.html` | `http://localhost/test/page.html` |
| `C:\xampp\htdocs\dou-setif\index.html` | `http://localhost/dou-setif/` |

عندما يطلب المتصفح **مجلداً** (مثل `/dou-setif/`) يبحث Apache تلقائياً داخله عن ملف اسمه `index.php` أو `index.html` ويعرضه. لهذا ستكون صفحتنا الرئيسية دائماً باسم `index`.

## إظهار امتدادات الملفات في Windows

يخفي Windows افتراضياً امتدادات الملفات، فقد تنشئ ملفاً تظنّه `index.html` وهو في الحقيقة `index.html.txt`. لتجنّب ذلك:
افتح مستكشف الملفات ← تبويب **عرض (View)** ← فعّل **ملحقات أسماء الملفات (File name extensions)**.

## تثبيت محرر الأكواد Visual Studio Code

1. نزّل **VS Code** من `https://code.visualstudio.com` وثبّته بالإعدادات الافتراضية. فعّل خيار **Add "Open with Code" action** ليظهر في القائمة عند النقر بالزر الأيمن.
2. افتحه، ثم من الشريط الجانبي الأيسر اضغط أيقونة **Extensions** (المربعات الأربعة) وثبّت الإضافة **PHP Intelephense**: تكمل لك أسماء الدوال وتكشف الأخطاء قبل التشغيل (سنحتاجها من الفصل 10).
3. من **File ← Auto Save** فعّل الحفظ التلقائي حتى لا تنسى الحفظ قبل تحديث المتصفح.

::: note
تأكّد أن الترميز المكتوب في الشريط السفلي لـ VS Code هو **UTF-8** (وهو الافتراضي). هذا ضروري لتظهر الحروف العربية سليمة. إذا رأيت يوماً رموزاً غريبة مثل `Ø§Ù„` بدل العربية فالسبب غالباً ملف محفوظ بترميز آخر أو اتصال بقاعدة البيانات بترميز خاطئ.
:::

بعض اختصارات VS Code التي ستوفّر عليك الكثير:

| الاختصار | وظيفته |
|---|---|
| **Ctrl+S** | حفظ الملف (إن لم تفعّل الحفظ التلقائي) |
| **Ctrl+F** / **Ctrl+H** | البحث / البحث والاستبدال داخل الملف |
| **Ctrl+/** | تحويل السطر إلى تعليق أو إلغاء التعليق |
| **Alt+↑** / **Alt+↓** | نقل السطر الحالي للأعلى أو للأسفل |
| **Shift+Alt+↓** | نسخ السطر الحالي تحته |
| **Ctrl+X** ثم **Ctrl+V** | قصّ ولصق (سننقل بهما قطعاً كاملة بين الملفات لاحقاً) |
| **Ctrl+G** | الانتقال إلى سطر برقمه (مفيد جداً مع أرقام الأسطر في الكتاب) |

## أدوات المطوّر في المتصفح

في Chrome أو Firefox أو Edge اضغط **F12** لتفتح أدوات المطوّر، وأهم تبويباتها:

| التبويب | فائدته |
|---|---|
| **Elements** | رؤية عناصر HTML وتجربة تعديل CSS مباشرة |
| **Console** | رؤية أخطاء JavaScript وتجربة الأوامر |
| **Network** | رؤية كل الطلبات التي ترسلها الصفحة (الصور، CSS، طلبات AJAX) وحالتها مثل 200 أو 404 |

وزر **تبديل وضع الجهاز** (أيقونة الهاتف) يعرض الصفحة كما تظهر على الهاتف، وهو مفيد لاختبار التصميم المتجاوب. واضغط **Ctrl+U** لترى «مصدر الصفحة» كما وصل إلى المتصفح.

## إنشاء مجلد المشروع الفارغ

الآن نبدأ مشروعنا. افتح مستكشف الملفات، وادخل إلى `C:\xampp\htdocs`، وأنشئ مجلداً جديداً اسمه:

```plaintext
dou-setif
```

(أو من نافذة الأوامر: `mkdir C:\xampp\htdocs\dou-setif`.)

ثم افتحه في VS Code: **File ← Open Folder ← C:\xampp\htdocs\dou-setif**. سيظهر المجلد فارغاً في الشريط الجانبي الأيسر (Explorer). من الآن، كل مسار يظهر في رأس صناديق الكود (مثل `index.html` أو `assets/images/logo.svg`) هو مسار **داخل هذا المجلد**.

افتح المتصفح على `http://localhost/dou-setif/`. بما أن المجلد فارغ سيعرض Apache صفحة بعنوان **Index of /dou-setif** وقائمة ملفات فارغة. هذا طبيعي تماماً: في الفصل التالي ننشئ أول ملف فتظهر مكانها صفحتنا.

::: try
أنشئ داخل المجلد ملفاً نصياً تجريبياً `test.txt` واكتب فيه أي جملة، ثم افتح `http://localhost/dou-setif/test.txt`. سترى الجملة في المتصفح: هذا يعني أن Apache يقدّم ملفات مجلدك. احذف الملف بعد التجربة.
:::

::: summary
- XAMPP يوفّر Apache (خادم الويب) وPHP وMySQL/MariaDB وphpMyAdmin.
- مواقعنا توضع في `C:\xampp\htdocs` وتُفتح عبر `http://localhost/...`.
- عندما نطلب مجلداً يعرض Apache ملف `index` الموجود فيه.
- VS Code هو المحرر، وأدوات المطوّر (F12) في المتصفح تساعدنا على فهم الصفحة.
- مجلد مشروعنا الفارغ: `C:\xampp\htdocs\dou-setif`.
:::
