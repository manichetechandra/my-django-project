# النماذج: من الصفوف إلى الكائنات

::: intro
الصنف `DB` يُرجع صفوفاً كمصفوفات خام. هذا يكفي للاستعلامات البسيطة، لكن موقعنا يحتاج أكثر: خبر «يعرف» كاتبه وصوره، وطلب «يعرف» اسم حالته بالعربية، وكائن «يحفظ نفسه» ويملأ تاريخ التعديل تلقائياً. في هذا الفصل نكتب الصنف الأساسي `Model` الذي سترثه كل جداول الموقع، والصنف `Page` لتقسيم النتائج إلى صفحات.
:::

## ماذا سنستطيع أن نكتب؟

بعد هذا الفصل والذي يليه، سيصبح الكود في المتحكمات والقوالب هكذا:

```php
$news = News::find(5);                       // كائن News أو null
echo $news['title'];                         // نقرؤه كأنه مصفوفة
echo $news['author']['username'];            // الكاتب يُجلب تلقائياً من جدول users
foreach ($news['images'] as $image) { ... }  // صور الخبر من news_images

$app = StudentApplication::find(12);
echo $app->get_status_display();             // 'قيد المراجعة' بدل 'under_review'

$latest = News::where('status = ?', ['published'], 'published_date DESC', 6);
$page   = News::paginate('status = ?', ['published'], 'published_date DESC', 9);

$msg = ContactMessage::create(['full_name' => 'أحمد', 'email' => 'a@b.dz', ...]);
$msg->update(['is_read' => true]);
$msg->delete();
```

هذه الطريقة تسمّى **Active Record**: كل صف في الجدول يصبح كائناً، وكل جدول يصبح صنفاً يرث `Model` ويحدد فقط ما يميّزه (اسم الجدول، العلاقات، الخيارات).

## الصنف Model

### الإعدادات والبنّاء

افتح `app/core/Model.php`:

@file app/core/Model.php 1-46

- **السطر 9** `abstract class`: صنف «مجرّد» لا يُنشأ منه كائن مباشرة، بل يُورث فقط. ويطبّق واجهتين جاهزتين في PHP:
  - `ArrayAccess`: تسمح بقراءة الكائن بالأقواس المربعة `$news['title']`، بشرط أن نكتب أربع دوال (`offsetGet` وأخواتها).
  - `JsonSerializable`: تحدد ما يظهر عند تحويل الكائن إلى JSON بـ `json_encode()`.
- **الأسطر 11–33**: خصائص **ثابتة** (`static`) قيمها فارغة هنا، وكل نموذج يعيد تعريف ما يحتاجه منها:

| الخاصية | معناها | مثال |
|---|---|---|
| `$table` | اسم الجدول | `'news'` |
| `$choices` | الرموز المسموحة لعمود وتسمياتها العربية | `'status' => ['draft' => 'مسودة', ...]` |
| `$belongsTo` | علاقة «ينتمي إلى»: عمود يشير إلى جدول آخر | `'author' => [User::class, 'author_id']` |
| `$hasMany` | علاقة «له عدة»: جدول آخر يشير إلينا | `'images' => [NewsImage::class, 'news_id', 'ORDER BY ...']` |
| `$booleans` | أعمدة نعم/لا تتحول إلى `true`/`false` | `['is_active', 'is_featured']` |
| `$defaults` | قيم افتراضية عند الإنشاء | `['status' => 'pending']` |
| `$createdFields` | أعمدة تأخذ وقت الإنشاء تلقائياً | `['created_at']` |
| `$updatedFields` | أعمدة تأخذ وقت كل تعديل تلقائياً | `['updated_at']` |

  `User::class` تُرجع اسم الصنف كنص `'User'`. نكتبها هكذا بدل النص لأن محرر الأكواد يتحقق منها وينبّهك إن أخطأت في الاسم.
- **السطر 35** `$attributes`: أعمدة الصف نفسه (`id`، `title`...).
- **السطر 36** `$loaded`: العلاقات التي جُلبت من قبل، حتى لا نستعلم قاعدة البيانات مرتين لنفس العلاقة.
- **الأسطر 38–46**: البنّاء يحفظ الصف، ويحوّل الأعمدة المنطقية إلى `true`/`false` (MySQL تُرجعها `1` و`0`). وهو `final` حتى لا يغيّر أي نموذج توقيعه، لأننا سننشئ الكائنات بـ `new static($row)`.

### قراءة الحقول والعلاقات

@file app/core/Model.php 48-108

قلب الصنف هو **`offsetGet($key)`** التي تُستدعى تلقائياً عند كتابة `$news['...']`، وتبحث بالترتيب:

1. **الأسطر 58–60**: هل هو عمود في الصف؟ نُرجعه.
2. **الأسطر 61–63**: هل جُلبت هذه العلاقة من قبل؟ نُرجعها من الذاكرة.
3. **الأسطر 64–68**: هل هو علاقة «ينتمي إلى»؟ نأخذ قيمة العمود الأجنبي (`author_id`)، ونجلب الكائن بـ `User::find()`، ونحفظه في `$loaded`. لاحظ `$class::find($id)`: استدعاء دالة ثابتة على صنف اسمه في متغير.
4. **الأسطر 69–75**: هل هو علاقة «له عدة»؟ نجلب كل الصفوف من الجدول الآخر التي يشير عمودها إلينا، مع الترتيب المحدد. والعبارة `+ [2 => '']` تضيف عنصراً ثالثاً فارغاً إن لم يُحدد ترتيب.
5. **السطر 76**: لا شيء: `null`.

هذا ما يسمّى **التحميل الكسول** (lazy loading): الكاتب لا يُجلب من قاعدة البيانات إلا إذا طلبه القالب فعلاً.

- **`offsetExists`**: تجعل `isset($news['main_image'])` و`empty(...)` تعملان بشكل طبيعي.
- **`offsetSet` و`offsetUnset`**: الكتابة `$news['title'] = '...'` والحذف `unset(...)`.
- **الأسطر 89–102**: الدوال **السحرية** `__get` و`__set` و`__isset` تجعل صيغة الخاصية `$news->title` تعمل أيضاً كالأقواس.
- **`setRelation()`**: لوضع علاقة جاهزة يدوياً. في لوحة الموظفين مثلاً نجلب الطلبات مع الطالب ونوع الطلب **باستعلام واحد** فيه `JOIN`، ثم نضع كل علاقة في مكانها بـ `setRelation()`، بدل استعلامين إضافيين لكل طلب من مئات الطلبات.

::: note
السطر 55 `#[\ReturnTypeWillChange]` «وسم» (attribute) يخبر PHP 8.1 وما بعده: «أعرف أن هذه الدالة بلا نوع إرجاع محدد، لا تُظهر تحذيراً». بدونه يظهر تحذير «Deprecated» في الإصدارات الحديثة، ونبقى بذلك متوافقين مع PHP 8.0.
:::

@file app/core/Model.php 110-140

- **`__call()`**: دالة سحرية تُستدعى عند استدعاء دالة **غير موجودة** على الكائن. نستغلها لنصنع دالة لكل عمود له خيارات: `get_status_display()` ← نستخرج اسم العمود `status` بتعبير نمطي، ونُرجع تسميته العربية من `$choices` (أو القيمة نفسها إن لم تكن لها تسمية). أي اسم آخر يرمي استثناء واضحاً.
- **`__toString()`**: ما يظهر عند طباعة الكائن كنص `echo $news`. نجرب أعمدة شائعة بالترتيب (`title` ثم `name`...) ونُرجع أول عمود غير فارغ. ستستعملها لوحة الإدارة لعرض أي كائن.
- **`toArray()` و`jsonSerialize()`**: الصف كمصفوفة عادية.

### الاستعلامات

@file app/core/Model.php 142-243

كل هذه الدوال **ثابتة**، نستدعيها على اسم الصنف: `News::find(5)`.

**`static` بدل `self`**: داخل `Model`، كلمة `static` تعني «الصنف الذي استُدعيت عليه الدالة فعلاً». فعند كتابة `News::find(5)` يصبح `static::$table` هو `'news'`، و`new static($row)` تنشئ كائن `News`. هذه الخاصية تسمّى **الربط الثابت المتأخر** (late static binding)، وهي التي تجعل صنفاً أساسياً واحداً يخدم 27 جدولاً.

| الدالة | عملها | مثال |
|---|---|---|
| `table()` | اسم الجدول | `News::table()` ← `'news'` |
| `choices('status')` | الخيارات كأزواج `[رمز, تسمية]` لبناء قوائم الاختيار | `[['draft', 'مسودة'], ...]` |
| `choiceMap('status')` | الخيارات كمصفوفة `رمز => تسمية` | |
| `hydrate($rows)` | تحويل صفوف إلى كائنات | |
| `query($sql, $params)` | استعلام كامل نكتبه بأنفسنا ← كائنات | استعلامات فيها `JOIN` |
| `first($sql, $params)` | مثله لكن كائن واحد أو `null` | |
| `where($where, $params, $orderBy, $limit, $offset)` | `SELECT *` بشرط وترتيب وحد | `News::where('is_featured = 1', [], 'id DESC', 3)` |
| `firstWhere(...)` | أول نتيجة لـ `where` | `User::firstWhere('username = ?', ['ali'])` |
| `all($orderBy)` | كل الصفوف | ``Statistic::all('`order`')`` |
| `find($id)` | بالمفتاح الأساسي | `News::find(5)` |
| `findOrFail($id)` | مثلها، أو صفحة 404 إن لم يوجد | في صفحات التفاصيل |
| `count($where, $params)` | عدد الصفوف | `News::count('status = ?', ['published'])` |
| `exists($where, $params)` | هل يوجد صف واحد على الأقل؟ | |
| `paginate(...)` | صفحة واحدة من النتائج (انظر `Page` أدناه) | |

- **السطر 192**: في `where()` نضيف `LIMIT` و`OFFSET` بعد تحويلهما إلى `(int)`، فلا يمكن حقن شيء من خلالهما.
- **السطر 213**: في `find()` نحوّل المعرّف إلى عدد صحيح، فـ `find('5abc')` تبحث عن 5.
- **`paginate()`** (الأسطر 237–243): تعدّ كل النتائج أولاً، ثم تنشئ كائن `Page` يحسب رقم الصفحة الصحيح (من `?page=` في الرابط إن لم يُمرَّر)، ثم تجلب صفوف تلك الصفحة فقط: إن كانت الصفحة 3 بـ 9 عناصر لكل صفحة فالإزاحة `(3 - 1) × 9 = 18`.

::: warning
مثل `DB`، الشرط `$where` والترتيب `$orderBy` يُكتبان في الاستعلام كما هما، فاكتبهما دائماً في الكود، وضع **القيم** في المصفوفة `$params` مع علامات `?`.
:::

### الكتابة

@file app/core/Model.php 245-314

- **`create($data)`**: تنشئ كائناً وتحفظه وتُرجعه (مع `id` الجديد).
- **`beforeSave($isNew)`**: دالة فارغة هنا، تعيد النماذج تعريفها لتنفيذ شيء قبل كل حفظ. مثلاً `News` ستولّد `slug` من العنوان، و`StudentApplication` ستولّد رقم الطلب. يسمّى هذا «خطّافاً» (hook).
- **`save()`**:
  1. **السطر 261**: لا يوجد `id`؟ إذن هو جديد.
  2. **الأسطر 262–273**: للجديد فقط: نملأ القيم الافتراضية الناقصة، ووقت الإنشاء.
  3. **الأسطر 274–276**: وقت التعديل في كل حفظ.
  4. **السطر 277**: نستدعي الخطّاف.
  5. **الأسطر 278–286**: نجهّز الأعمدة: بدون `id`، والقيم المنطقية إلى `1`/`0`، ونحذف المصفوفات والكائنات لأنها ليست أعمدة (قد تكون علاقات وضعناها في الكائن).
  6. **الأسطر 287–291**: `INSERT` للجديد مع حفظ رقمه، أو `UPDATE` للموجود.
- **`update($data)`**: تحدّث أعمدة **محددة فقط** مباشرة في قاعدة البيانات، دون المرور على الخطّاف وأوقات التعديل. مناسبة لعمليات صغيرة مثل زيادة عدد المشاهدات.
- **`delete()`**: تحذف الصف.

## الصنف Page: تقسيم النتائج إلى صفحات

قائمة الأخبار قد تحتوي مئات الأخبار، فنعرض 9 في كل صفحة مع أزرار «السابق» و«التالي» وأرقام الصفحات. افتح `app/core/Page.php`:

@file app/core/Page.php 1-34

- **الأسطر 8–12**: العناصر المعروضة، والعدد الكلي، وعدد العناصر لكل صفحة، ورقم الصفحة الحالية، وعدد الصفحات.
- **السطر 19**: عدد الصفحات = العدد الكلي ÷ عدد العناصر لكل صفحة، مقرّباً للأعلى بـ `ceil` (20 خبراً ÷ 9 = 2.2 ← 3 صفحات)، وصفحة واحدة على الأقل حتى لو لم توجد نتائج.
- **الأسطر 21–25**: رقم الصفحة يأتي من الرابط، أي من الزائر، فلا نثق به: `filter_var` مع `FILTER_VALIDATE_INT` تقبل الأعداد الصحيحة فقط، والرقم غير الصالح أو السالب يصبح 1، والرقم الأكبر من عدد الصفحات يصبح آخر صفحة. هكذا `?page=abc` و`?page=999` لا تكسران الصفحة.
- **`fromArray()`**: صفحة من مصفوفة جاهزة (عندما تأتي النتائج من مصادر عدة، كما في صفحة البحث).

@file app/core/Page.php 36-87

دوال يستعملها قالب أزرار الصفحات:

| الدالة | تُرجع |
|---|---|
| `has_next()` و`has_previous()` | هل توجد صفحة تالية / سابقة؟ |
| `has_other_pages()` | هل توجد أكثر من صفحة؟ (وإلا لا نعرض الأزرار أصلاً) |
| `next_page_number()` و`previous_page_number()` | رقم التالية / السابقة |
| `page_range()` | كل الأرقام `[1, 2, 3, ...]` |
| `start_index()` و`end_index()` | لعبارة مثل «عرض 10–18 من 25» |
| `url(3)` | رابط الصفحة 3 **مع الإبقاء على بقية المعاملات**: إن كان الزائر يبحث `?q=منحة&page=1` يصبح الرابط `?q=منحة&page=3`. `http_build_query` تبني نص المعاملات وترمّزه |
| `isEmpty()` | لا توجد نتائج؟ |

@file app/core/Page.php 89-127

ثلاث واجهات تجعل كائن `Page` يتصرف كمصفوفة في القوالب:

- **`IteratorAggregate`** مع `getIterator()`: تسمح بـ `foreach ($page as $news)` مباشرة على العناصر.
- **`Countable`** مع `count()`: تسمح بـ `count($page)`.
- **`ArrayAccess`**: تسمح بـ `$page['number']` و`$page['paginator']['num_pages']`. الكتابة (`offsetSet`) لا تفعل شيئاً عمداً.

## التجربة

النماذج الحقيقية في الفصل القادم. لنجرّب الآن بنموذجين مؤقتين نعرّفهما داخل `hello.php` نفسه:

```php hello.php (ملف مؤقت)
<?php
require __DIR__ . '/app/bootstrap.php';

class TestNewsImage extends Model
{
    protected static string $table = 'news_images';
}

class TestNews extends Model
{
    protected static string $table = 'news';
    protected static array $choices = [
        'status' => ['draft' => 'مسودة', 'published' => 'منشور', 'archived' => 'مؤرشف'],
    ];
    protected static array $hasMany = ['images' => [TestNewsImage::class, 'news_id']];
}

echo '<div dir="rtl" style="font-family: Tahoma">';
foreach (TestNews::where('1', [], 'published_date DESC', 5) as $n) {
    echo '<p>' . e($n['title']) . ' — ' . $n->get_status_display()
       . ' — عدد الصور: ' . count($n['images']) . '</p>';
}

$page = TestNews::paginate('1', [], 'id', 3);
echo '<hr><p>الصفحة ' . $page->number . ' من ' . $page->numPages
   . ' (عرض ' . $page->start_index() . '–' . $page->end_index() . ' من ' . $page->total . ')</p>';
foreach ($page as $n) {
    echo '<p>' . e($n) . '</p>';
}
echo '</div>';
```

افتح `hello.php` ثم `hello.php?page=2` ثم `hello.php?page=999` و`hello.php?page=abc`، ولاحظ كيف يتغير الجزء الثاني ويبقى صالحاً دائماً. ولاحظ أن `e($n)` طبعت عنوان الخبر بفضل `__toString()`.

::: try
أضف السطر `echo $n->get_title_display();` داخل الحلقة الأولى. ماذا يُطبع؟ (العنوان نفسه، لأن `title` ليس له خيارات). ثم جرّب `$n->hello();` وشاهد الاستثناء «TestNews::hello() غير موجودة».
:::

::: summary
- كل جدول = صنف يرث `Model` ويحدد `$table` وعلاقاته وخياراته.
- `$obj['col']` تقرأ عموداً أو تجلب علاقة عند أول طلب (تحميل كسول).
- `get_FIELD_display()` تترجم الرموز إلى تسمياتها العربية.
- `find` و`where` و`count` و`paginate` للقراءة، و`create` و`save` و`update` و`delete` للكتابة.
- `static::` تجعل الدوال الموروثة تعمل على جدول الصنف الذي استُدعيت عليه.
- `Page` يحسب الصفحات بأمان ويُستعمل في `foreach` كمصفوفة.
:::
