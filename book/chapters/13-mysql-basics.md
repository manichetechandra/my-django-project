# قاعدة البيانات ولغة SQL

::: intro
بياناتنا الآن مصفوفات مكتوبة داخل `index.php`: أفضل من HTML المكرر، لكن تعديلها ما زال يحتاج فتح الكود. الحل الحقيقي **قاعدة بيانات**: مخزن منظّم للبيانات، نضيف إليه ونعدّل ونحذف بأوامر بسيطة (وبعد ذلك من لوحة تحكم)، وتقرأ منه الصفحة في كل مرة. في هذا الفصل نفهم كيف تُنظَّم البيانات في جداول، ونتعلّم لغة **SQL** على قاعدة بيانات تجريبية في phpMyAdmin.
:::

## ما هي قاعدة البيانات؟

قاعدة البيانات العلائقية مجموعة **جداول**، وكل جدول يشبه ورقة Excel:

- **الأعمدة** (columns): أنواع المعلومات، مثل العنوان والتاريخ وعدد المشاهدات.
- **الصفوف** (rows): السجلات نفسها، فكل خبر صف.

لاحظ التشابه مع مصفوفة الأخبار التي كتبناها في الفصل 11: كل خبر فيها مصفوفة ترابطية بمفاتيح (`title`، `published_date`...)، وهذه المفاتيح ستصبح **أعمدة** جدول الأخبار، وكل خبر **صفاً**:

| id | title | published_date | views_count | show_in_ticker |
|---|---|---|---|---|
| 1 | صرف الشطر الأول من المنحة الجامعية | 2026-10-12 09:00:00 | 512 | 1 |
| 2 | تدشين مكتبة جديدة بالإقامة الجامعية دباغين | 2026-10-05 10:30:00 | 130 | 0 |
| 3 | تعزيز خطوط النقل الجامعي نحو القطب الجامعي الباز | 2026-09-20 08:00:00 | 98 | 0 |

العمود `id` جديد: **رقم تعريف** فريد لكل صف، يضعه MySQL تلقائياً (1، 2، 3...)، ونستعمله لنشير إلى صف بعينه.

**MySQL** (ونسختها المتوافقة **MariaDB** الموجودة في XAMPP) هو البرنامج الذي يخزّن هذه الجداول وينفّذ أوامرنا عليها. ولغة **SQL** هي لغة هذه الأوامر.

## phpMyAdmin

تأكّد أن **MySQL** يعمل في لوحة XAMPP (خلفية خضراء)، ثم افتح `http://localhost/phpmyadmin` (أو زر **Admin** بجانب MySQL). هذه واجهة رسومية لإدارة قواعد البيانات من المتصفح. المستخدم الافتراضي في XAMPP هو `root` **بدون كلمة مرور**، ولهذا تدخل مباشرة.

| الجزء | فائدته |
|---|---|
| القائمة اليسرى | قواعد البيانات وجداولها. **New** لإنشاء قاعدة بيانات جديدة |
| تبويب **SQL** | كتابة أوامر SQL وتنفيذها بزر **Go** |
| **Browse** | عرض صفوف جدول وتعديلها أو حذفها بالنقر |
| **Structure** | أعمدة الجدول وأنواعها وفهارسه |
| **Insert** | إضافة صف بنموذج |
| **Import** / **Export** | استيراد ملف `.sql` / تصدير نسخة احتياطية |

## أنواع البيانات

كل عمود له **نوع** يحدد ما يقبله. هذه الأنواع التي يستعملها موقعنا:

| النوع | ماذا يخزّن | مثال من الموقع |
|---|---|---|
| `INT` | عدد صحيح (حتى حوالي 2 مليار) | `views_count`، `order` |
| `INT UNSIGNED` | عدد صحيح موجب فقط (ضعف المدى) | المعرّفات `id` |
| `TINYINT(1)` | عدد صغير؛ نستعمله لـ «نعم/لا» (1 أو 0) | `is_active`، `show_in_ticker` |
| `VARCHAR(n)` | نص قصير بحد أقصى n حرف | `title VARCHAR(300)` |
| `TEXT` | نص طويل (حتى 64 كيلوبايت) | `summary` ملخص الخبر |
| `MEDIUMTEXT` | نص طويل جداً (حتى 16 ميغابايت) | `content` محتوى الخبر |
| `DATE` | تاريخ فقط `2026-10-20` | تاريخ النشاط |
| `DATETIME` | تاريخ ووقت `2026-10-12 09:00:00` | `published_date`، `created_at` |
| `DECIMAL(4,2)` | عدد عشري دقيق | معدّل الطالب `15.75` |

::: note
لا نخزّن الصور داخل قاعدة البيانات، بل نحفظها في مجلد `uploads/` كما نفعل الآن، ونخزّن في الجدول **مسارها** فقط كنص، مثل `news/main/bourse.jpg`. هذا بالضبط ما كتبناه في المصفوفات.
:::

## قيود الأعمدة والمفاتيح

| القيد | معناه |
|---|---|
| `NOT NULL` | الحقل إجباري، لا يقبل «لا شيء» |
| `NULL` | الحقل اختياري |
| `DEFAULT قيمة` | القيمة التي توضع إن لم نحدّد قيمة عند الإضافة |
| `AUTO_INCREMENT` | يأخذ تلقائياً الرقم التالي: 1، 2، 3... |
| `PRIMARY KEY` | **المفتاح الأساسي**: معرّف فريد لكل صف (عندنا دائماً `id`) |
| `UNIQUE KEY` | لا يسمح بتكرار القيمة، مثل اسم المستخدم أو `slug` الخبر |
| `KEY` (فهرس) | يسرّع البحث والترتيب على هذا العمود، مثل فهرس الكتاب |
| `FOREIGN KEY` | **مفتاح أجنبي**: يربط الصف بصف في جدول آخر |

### العلاقات بين الجداول

سيكون لكل خبر لاحقاً **معرض صور** (عدة صور). بدل وضع الصور في أعمدة الخبر نفسه (كم عموداً؟ 3؟ 10؟)، نصنع جدولاً للصور فيه عمود `news_id` يحمل رقم الخبر الذي تنتمي إليه الصورة:

جدول `news_images`:

| id | news_id | image |
|---|---|---|
| 10 | 1 | news/gallery/a.jpg |
| 11 | 1 | news/gallery/b.jpg |
| 12 | 2 | news/gallery/c.jpg |

الخبر رقم 1 له صورتان، والخبر رقم 2 له صورة واحدة. هذه علاقة **واحد إلى متعدد**. والمفتاح الأجنبي يضمن ألا نضيف صورة لخبر غير موجود، ويحدد ماذا يحدث عند حذف الخبر:

- `ON DELETE CASCADE`: احذف الصور معه تلقائياً.
- `ON DELETE SET NULL`: أبقِ الصف لكن اجعل الرابط `NULL` (مثلاً عند حذف حساب كاتب الخبر يبقى الخبر بلا كاتب).

## الترميز: utf8mb4

لكي تُحفظ العربية سليمة يجب أن تكون قاعدة البيانات والجداول والاتصال كلها بترميز **utf8mb4**، مع **الترتيب** (collation) `utf8mb4_unicode_ci`. الترتيب يحدد كيف تُقارن النصوص وتُرتّب؛ و`ci` تعني أن المقارنة لا تفرّق بين الأحرف الكبيرة والصغيرة.

::: warning
تجنّب الترميز القديم `utf8` (بدون mb4) في MySQL: فهو لا يدعم إلا 3 بايتات للحرف، فيرفض الرموز التعبيرية وبعض الحروف. و`latin1` يحوّل العربية إلى علامات استفهام `????`.
:::

## لغة SQL خطوة بخطوة

لنتدرّب على قاعدة بيانات **تجريبية** نحذفها في آخر الفصل. في phpMyAdmin اضغط تبويب **SQL** في الأعلى، واكتب الأوامر واضغط **Go**.

### إنشاء قاعدة بيانات وجدول

```sql مثال
CREATE DATABASE test_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE test_db;

CREATE TABLE `news` (
  `id`             INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `title`          VARCHAR(300) NOT NULL,
  `status`         VARCHAR(20)  NOT NULL DEFAULT 'published',
  `views_count`    INT          NOT NULL DEFAULT 0,
  `published_date` DATETIME     NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

- `CREATE DATABASE` تنشئ قاعدة بيانات، و`USE` تختارها لما بعدها.
- `CREATE TABLE` تنشئ جدولاً: بين القوسين الأعمدة، كل عمود: اسمه، نوعه، قيوده. ثم المفتاح الأساسي.
- العلامة المائلة للخلف `` ` `` حول الأسماء اختيارية غالباً، لكنها ضرورية إذا كان الاسم كلمة محجوزة في SQL مثل `order` (وهو عمود موجود في عدة جداول عندنا!). لذلك نضعها دائماً.
- `ENGINE=InnoDB`: محرك التخزين الذي يدعم المفاتيح الأجنبية.
- كل أمر SQL ينتهي بفاصلة منقوطة.

### الإضافة: INSERT

```sql مثال
INSERT INTO `news` (`title`, `views_count`, `published_date`)
VALUES ('صرف الشطر الأول من المنحة الجامعية', 512, '2026-10-12 09:00:00');

-- عدة صفوف دفعة واحدة
INSERT INTO `news` (`title`, `status`) VALUES
  ('تدشين مكتبة جديدة', 'published'),
  ('خبر قيد التحرير', 'draft');
```

لم نحدد `id` لأنه `AUTO_INCREMENT`، ولا `status` في الأمر الأول فأخذ القيمة الافتراضية `published`. والسطر الذي يبدأ بـ `--` تعليق. اضغط على الجدول `news` في القائمة اليسرى ثم **Browse**: سترى الصفوف الثلاثة بأرقامها 1 و2 و3.

### القراءة: SELECT

```sql مثال
SELECT * FROM `news`;                                   -- كل الأعمدة وكل الصفوف
SELECT `id`, `title` FROM `news`;                       -- أعمدة محددة
SELECT * FROM `news` WHERE `status` = 'published';      -- بشرط
SELECT * FROM `news` WHERE `status` = 'published' AND `views_count` > 100;
SELECT * FROM `news` ORDER BY `published_date` DESC;    -- ترتيب تنازلي (الأحدث أولاً)
SELECT * FROM `news` ORDER BY `id` DESC LIMIT 5;        -- أحدث 5 فقط
SELECT * FROM `news` LIMIT 10 OFFSET 20;                -- الصفحة الثالثة (10 في كل صفحة)
SELECT * FROM `news` WHERE `title` LIKE '%منحة%';       -- يحتوي كلمة «منحة»
SELECT * FROM `news` WHERE `published_date` IS NULL;    -- القيم الفارغة (لا نستعمل = NULL)
```

| الجزء | دوره |
|---|---|
| `SELECT ... FROM` | ماذا نقرأ ومن أي جدول (`*` كل الأعمدة) |
| `WHERE` | تصفية الصفوف بشرط؛ مع `AND` و`OR` و`NOT` |
| `ORDER BY ... ASC/DESC` | الترتيب تصاعدياً (الافتراضي) أو تنازلياً |
| `LIMIT n OFFSET m` | أخذ n صفاً بعد تخطّي m صفاً: أساس **تقسيم الصفحات** |
| `LIKE '%نص%'` | البحث الجزئي: `%` تعني «أي أحرف» |

قارن `SELECT * FROM news WHERE show_in_ticker = 1` بالحلقة التي كتبناها في الفصل 11 لاستخراج أخبار الشريط: نفس الفكرة، لكن قاعدة البيانات تقوم بالعمل.

### الدوال التجميعية

```sql مثال
SELECT COUNT(*) FROM `news`;                              -- عدد الأخبار
SELECT SUM(`views_count`) FROM `news`;                    -- مجموع المشاهدات
SELECT `status`, COUNT(*) AS total FROM `news` GROUP BY `status`;   -- العدد لكل حالة
```

`COUNT(*)` هي ما سنستعمله لحساب أرقام قسم الإحصائيات تلقائياً. و`GROUP BY` يجمع الصفوف المتشابهة في مجموعات، و`AS` تعطي العمود الناتج اسماً.

### التعديل والحذف: UPDATE وDELETE

```sql مثال
UPDATE `news` SET `views_count` = `views_count` + 1 WHERE `id` = 1;
UPDATE `news` SET `status` = 'archived', `title` = 'عنوان جديد' WHERE `id` = 3;
DELETE FROM `news` WHERE `id` = 3;
```

::: warning
**لا تنسَ `WHERE`** مع UPDATE وDELETE! الأمر `DELETE FROM news;` بلا شرط يحذف **كل** الأخبار، و`UPDATE news SET title='x';` يغيّر عناوين كل الأخبار.
:::

### الربط بين الجداول: JOIN

```sql مثال
SELECT n.`title`, u.`username`
FROM `news` n
LEFT JOIN `users` u ON u.`id` = n.`author_id`;
```

يجلب عنوان كل خبر مع اسم كاتبه من جدول المستخدمين (سنحتاج هذا في لوحة الموظفين). `n` و`u` أسماء مختصرة للجدولين، و`LEFT JOIN` تُبقي الخبر حتى لو لم يكن له كاتب.

### حذف جدول أو قاعدة بيانات

```sql مثال
DROP TABLE IF EXISTS `news`;     -- يحذف الجدول وكل بياناته
DROP DATABASE test_db;           -- يحذف قاعدة البيانات كلها
```

::: try
قبل أن تحذف قاعدة البيانات التجريبية:
1. أضف إلى `test_db.news` خمسة أخبار بتواريخ مختلفة.
2. اكتب استعلاماً يجلب الأخبار المنشورة فقط، من الأحدث إلى الأقدم، وأول 3 منها فقط.
3. زد مشاهدات الخبر رقم 2 بمقدار 10.
4. احذف الأخبار التي حالتها `draft`.

ثم احذف القاعدة بالأمر `DROP DATABASE test_db;`.
:::

::: summary
- قاعدة البيانات جداول؛ الأعمدة أنواع المعلومات والصفوف السجلات، ومفاتيح مصفوفاتنا ستصبح أعمدة.
- كل عمود له نوع (`INT`, `VARCHAR`, `TEXT`, `DATETIME`...) وقيود (`NOT NULL`, `DEFAULT`, `AUTO_INCREMENT`, `PRIMARY KEY`, `UNIQUE`, `FOREIGN KEY`).
- الترميز `utf8mb4` مع `utf8mb4_unicode_ci` للعربية.
- أوامر SQL الأساسية: `CREATE`، `INSERT`، `SELECT` (مع `WHERE`/`ORDER BY`/`LIMIT`)، `UPDATE`، `DELETE`، و`COUNT(*)`.
:::
