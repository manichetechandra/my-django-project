# من HTML إلى PHP

::: intro
في هذا الفصل تتحول صفحتنا من ملف HTML ثابت إلى ملف **PHP**. سنرى أن الصفحة تبقى تعمل كما هي تماماً، ثم نكتب أول سطور PHP داخلها: متغيرات، وطباعة، والسنة الحالية تلقائياً في التذييل. ونتعلّم كيف نقرأ رسائل الأخطاء.
:::

## ما هي PHP؟

**PHP** لغة برمجة تعمل **على الخادم**. عندما يطلب الزائر ملفاً امتداده `.php`، لا يرسله Apache كما هو، بل يسلّمه أولاً لمفسّر PHP الذي **ينفّذ** ما فيه من أوامر، ثم يُرسل **الناتج** (HTML عادياً) إلى المتصفح:

<div class="flow">
  <div class="st"><b>المتصفح</b>يطلب index.php</div><span class="ar">←</span>
  <div class="st"><b>Apache</b>يرى الامتداد .php</div><span class="ar">←</span>
  <div class="st hl"><b>PHP</b>ينفّذ الأوامر<small>&lt;?php ... ?&gt;</small></div><span class="ar">←</span>
  <div class="st"><b>HTML فقط</b>يعود إلى المتصفح</div>
</div>

الفرق المهم بين PHP وJavaScript التي رأيناها: JavaScript تُرسل إلى المتصفح وتعمل **فيه** (والزائر يستطيع قراءتها بـ Ctrl+U)، أما PHP فتعمل **قبل** الإرسال، والمتصفح لا يرى منها شيئاً، فقط نتيجتها. لهذا تستطيع PHP أن تتصل بقاعدة البيانات وتحفظ كلمات المرور دون أن يراها أحد.

## الخطوة الأولى: إعادة التسمية

في VS Code اضغط بالزر الأيمن على `index.html` واختر **Rename**، وغيّر الاسم إلى:

```plaintext
index.php
```

افتح `http://localhost/dou-setif/` وحدّث الصفحة. لا شيء تغيّر! والسبب: كل ما هو **خارج** وسوم PHP يُرسل إلى المتصفح كما هو. ملف PHP بلا أي كود PHP هو ببساطة صفحة HTML. هذه أهم فكرة في الفصل: **PHP تُضاف إلى HTML، ولا تحلّ محلّه**.

::: note
عندما يطلب المتصفح المجلد `/dou-setif/` يبحث Apache عن `index.php` أولاً ثم `index.html`، فلا تُبقِ الملفين معاً.
:::

## تأكّد من إعدادات PHP

قبل أن نكتب الكود، تأكّد أن PHP **يعرض الأخطاء** أثناء التطوير، وإلا ستظهر لك صفحة بيضاء فارغة عند أي خطأ دون أن تعرف السبب. افتح ملف إعدادات PHP: من لوحة XAMPP **Apache ← Config ← PHP (php.ini)**، وابحث (Ctrl+F) عن هذه الأسطر وتأكّد من قيمها:

```ini php.ini
display_errors = On
error_reporting = E_ALL
date.timezone = Africa/Algiers

extension=fileinfo
extension=mbstring
extension=pdo_mysql
extension=zip

upload_max_filesize = 40M
post_max_size = 40M
```

- `date.timezone` المنطقة الزمنية: الجزائر، حتى تكون الساعة والتاريخ صحيحين.
- أسطر `extension` تفعّل **امتدادات** PHP سنحتاجها في الكتاب: `pdo_mysql` للاتصال بقاعدة البيانات (الفصل 15)، و`mbstring` لمعالجة النصوص العربية، و`fileinfo` لفحص نوع الملفات المرفوعة (الفصل 30)، و`zip` لتصدير ملفات Excel (الفصل 34). في هذا الملف، السطر الذي يبدأ بفاصلة منقوطة `;` **معطّل**: إن وجدت `;extension=zip` فاحذف الفاصلة المنقوطة.
- `upload_max_filesize` أقصى حجم لملف واحد يرفعه الزائر، و`post_max_size` أقصى حجم للطلب كله (كل الملفات والحقول معاً).

بعد أي تعديل على `php.ini` **أوقف Apache وشغّله من جديد** (Stop ثم Start).

::: tip
لمعرفة إصدار PHP وكل إعداداته، أنشئ ملفاً مؤقتاً `info.php` فيه سطر واحد `<?php phpinfo();` وافتح `http://localhost/dou-setif/info.php`. تأكّد أن **PHP Version** يبدأ بـ 8، وأن في الصفحة أقساماً باسم **pdo_mysql** و**mbstring** و**fileinfo** و**zip**. ثم **احذف الملف**: لا يجب أن يبقى على موقع حقيقي لأنه يكشف معلومات عن الخادم.
:::

## أول سطور PHP

كود PHP يُكتب بين الوسمين `<?php` و`?>`. اكتب هذه الأسطر في **أول** الملف `index.php`، قبل `<!DOCTYPE html>`:

@stage home php-top

- **السطر 1**: `<?php` بداية كود PHP.
- **السطر 2**: تعليق يبدأ بـ `//`: ملاحظة للمبرمج لا تُنفَّذ (مثل `<!-- -->` في HTML و`/* */` في CSS).
- **الأسطر 3–4**: **متغيّران**. المتغيّر صندوق له اسم نضع فيه قيمة لنستعملها لاحقاً. في PHP يبدأ اسم المتغيّر دائماً بعلامة الدولار `$`، والعلامة `=` تعني «ضع القيمة في المتغيّر» (إسناد). النصوص تُكتب بين علامتي تنصيص `'...'`. وكل تعليمة تنتهي بفاصلة منقوطة `;`.
- **السطر 5**: `?>` نهاية كود PHP. ما بعده HTML عادي يُرسل كما هو.

ثم استعمل المتغيّرين في عنوان الصفحة. استبدل سطر `<title>` بهذا السطر:

@stage home title-php

`<?= ... ?>` تعني «اطبع هنا قيمة ما بداخلها». فيصبح العنوان: «الصفحة الرئيسية - مديرية الخدمات الجامعية سطيف»، تماماً كما كان. الفرق أن القيمة صارت تأتي من متغيّر: عندما تكون لدينا عدة صفحات، كل صفحة تضع عنوانها في `$page_title` ويبقى الباقي مشتركاً.

وأخيراً السنة في التذييل. استبدل سطر حقوق النشر بهذا:

@stage home footer-year-php

`date('Y')` **دالة** جاهزة في PHP: تُرجع التاريخ الحالي بالشكل الذي نطلبه، و`'Y'` يعني السنة بأربعة أرقام. من الآن ستتغيّر السنة وحدها في كل سنة جديدة.

حدّث الصفحة: لا تغيير ظاهر! افتح المصدر (**Ctrl+U**) وابحث عن «جميع الحقوق»: ستجد `© 2026` لا `<?= date('Y') ?>`. وفي أول المصدر لا أثر للمتغيّرات: المتصفح استلم HTML فقط.

## echo والطباعة

`<?= $x ?>` اختصار للأمر `<?php echo $x; ?>`. الأمر `echo` يطبع نصاً في مكانه من الصفحة. هذه أمثلة تجرّبها في ملف مؤقت `test.php` (ثم تحذفه):

```php مثال: test.php
<?php
$name = 'أحمد';
$year = 2026;

echo 'مرحباً';                       // مرحباً
echo '<br>';                         // نطبع HTML أيضاً!
echo 'مرحباً ' . $name;              // النقطة . تلصق نصين: مرحباً أحمد
echo "<p>مرحباً $name</p>";          // بين التنصيص المزدوج "..." تُستبدل المتغيرات بقيمها
echo '<p>مرحباً $name</p>';          // بين المفرد '...' لا تُستبدل: تطبع $name حرفياً
echo $year + 1;                      // 2027: عمليات حسابية
echo date('d/m/Y');                  // تاريخ اليوم مثل 29/10/2026
```

## أنواع القيم

```php مثال
<?php
$title     = 'افتتاح المكتبة';   // نص (string)
$views     = 150;                // عدد صحيح (int)
$price     = 1200.50;            // عدد عشري (float)
$is_active = true;               // منطقي (bool): true أو false
$image     = null;               // «لا شيء» (null)

var_dump($views);                // يعرض النوع والقيمة: int(150) — مفيد جداً لاكتشاف الأخطاء
```

::: note
أسماء المتغيرات **حسّاسة لحالة الأحرف**: `$Title` و`$title` متغيران مختلفان. اكتبها دائماً بحروف صغيرة وشرطة سفلية بين الكلمات (`$page_title`)، وهو الأسلوب المتّبع في كل المشروع.
:::

## عندما يحدث خطأ

جرّب أن تحذف الفاصلة المنقوطة في آخر السطر 3، واحفظ وحدّث الصفحة. ستظهر رسالة مثل:

```plaintext
Parse error: syntax error, unexpected variable "$page_title" in C:\xampp\htdocs\dou-setif\index.php on line 4
```

اقرأها بهدوء: **نوع الخطأ** (Parse error: خطأ في كتابة اللغة نفسها)، **الوصف** (لم يكن يتوقع متغيراً هنا)، **الملف**، و**رقم السطر**. لاحظ أن رقم السطر 4 لا 3: PHP لاحظت المشكلة عندما وصلت إلى السطر التالي ولم تجد `;`. فإذا لم تجد الخطأ في السطر المذكور، انظر في السطر الذي قبله. أرجع الفاصلة المنقوطة.

ثم جرّب أن تكتب في `<title>` اسم متغيّر غير موجود، مثل `<?= $page_titel ?>` (بخطأ إملائي):

```plaintext
Warning: Undefined variable $page_titel in C:\xampp\htdocs\dou-setif\index.php on line 14
```

هذا **تحذير** لا خطأ قاتل: الصفحة تكمل، لكن المكان يبقى فارغاً. أصلحه.

| الرسالة | معناها | السبب الشائع |
|---|---|---|
| `Parse error: syntax error` | PHP لم تفهم الكود | `;` أو `)` أو `}` أو علامة تنصيص ناقصة |
| `Warning: Undefined variable` | متغيّر غير موجود | خطأ إملائي في الاسم، أو لم يُسند بعد |
| `Warning: Undefined array key` | مفتاح غير موجود في مصفوفة | (سنراه في الفصل القادم) |
| `Fatal error: Call to undefined function` | دالة غير موجودة | خطأ في الاسم، أو ملف لم يُضمَّن |

1. أضف إلى `php-top` متغيّراً ثالثاً `$city = 'سطيف';` واطبعه في مكان ما من الصفحة بـ `<?= $city ?>`، ثم احذفه.
2. غيّر `date('Y')` إلى `date('d/m/Y H:i')` لترى التاريخ والساعة، ثم أرجعها.
3. اكتب في `test.php`: `echo 7 * 6;` وجرّب العمليات `+ - * /` و`%` (باقي القسمة).
:::

::: summary
- PHP تعمل على الخادم وتُرسل الناتج فقط؛ ملف `.php` بلا كود PHP يُرسل كما هو.
- الكود بين `<?php` و`?>`، و`<?= $x ?>` تطبع قيمة.
- المتغيّرات تبدأ بـ `$`، والتعليمات تنتهي بـ `;`، والنقطة `.` تلصق النصوص.
- `date('Y')` تجعل السنة تلقائية.
- رسالة الخطأ تخبرك بالنوع والملف والسطر؛ ابحث في السطر المذكور والذي قبله.
:::
