# المصفوفات والحلقات: نكتب الشكل مرة واحدة

::: intro
في صفحتنا ثلاث شرائح، وخمسة أخبار، وثلاث بطاقات، وأربعة أقسام، وسبع إقامات... وكل عنصر نسخة من غيره بنص مختلف. في هذا الفصل نفصل **البيانات** عن **الشكل**: نضع البيانات في **مصفوفات** PHP أعلى الملف، ونكتب شكل العنصر **مرة واحدة** داخل **حلقة** تكرّره لكل عنصر. ستبقى الصفحة كما هي تماماً، لكن ملفها سيصغر ويصبح تعديله سهلاً.
:::

::: note
أرقام الأسطر في صناديق هذا الفصل هي أرقامها في `index.php` **بعد إكمال الفصل كله**. أثناء العمل قد تختلف أرقامك قليلاً لأن بعض الأقسام لم تتحول بعد؛ اعتمد على النص الذي يحدد مكان كل قطعة.
:::

## الدوال: أداة الطباعة الآمنة e()

قبل أن نطبع أي نص في الصفحة نحتاج أداة صغيرة. استبدل كتلة PHP التي في أول الملف (الأسطر الخمسة من الفصل السابق) بهذه الأسطر:

@stage home php-open

@stage home php-func

@stage home php-close

- **الأسطر 1–6**: كما في الفصل السابق، مع تعليق عنوان أوضح. لاحظ أننا **لم نغلق** `?>` بعدها مباشرة: سنضيف البيانات تحتها.
- **الأسطر 8–13**: **دالة** من صنعنا اسمها `e`. الدالة مجموعة أوامر لها اسم، نكتبها مرة ونستدعيها متى شئنا:
  - `function e($value)`: تعريف دالة اسمها `e` تستقبل قيمة في المتغيّر `$value` (يسمّى **معامِلاً**).
  - بين `{ }` جسم الدالة، و`return` تعني «أرجع هذه النتيجة لمن استدعاني».
  - `htmlspecialchars(...)` دالة جاهزة في PHP تحوّل الرموز الخاصة في HTML إلى كيانات: `<` تصبح `&lt;` و`"` تصبح `&quot;`... و`(string)` تحوّل القيمة إلى نص أولاً (الأرقام مثلاً). و`ENT_QUOTES` و`'UTF-8'` إعدادان: حوّل علامتي التنصيص المفردة والمزدوجة، والترميز UTF-8.
  - السطر 8: تعليق توثيقي بين `/** */` يشرح عمل الدالة.
- **السطر 157** (في آخر الكتلة): `?>` نهاية كود PHP. كل ما سنضيفه من بيانات يوضع **قبله**.

::: why
لماذا لا نطبع النص مباشرة؟ لأن البيانات قريباً ستأتي من قاعدة البيانات، ومن نماذج يكتبها الزوار (رسائل «اتصل بنا»، أسماء الطلبة...). لو كتب أحدهم في اسمه `<script>...</script>` وطبعناه كما هو، لنفّذه متصفح كل من يفتح الصفحة! هذا هجوم مشهور اسمه **XSS**. الدالة `e()` تحوّل النص إلى نص بريء يُعرض ولا يُنفَّذ. القاعدة الذهبية: **كل قيمة متغيّرة تُطبع داخل HTML تمرّ عبر `e()`**.
:::

احفظ وحدّث: الصفحة تعمل كما هي (عرّفنا دالة لكننا لم نستعملها بعد).

## المصفوفات

**المصفوفة** (array) متغيّر يحمل عدة قيم. نوعان:

```php مثال
<?php
// مصفوفة مرقّمة: القيم مرتّبة، وأرقامها (الفهارس) تبدأ من 0
$cities = ['سطيف', 'العلمة', 'عين ولمان'];
echo $cities[0];               // سطيف
echo count($cities);           // 3: عدد العناصر
$cities[] = 'بوقاعة';          // [] بلا رقم = أضف عنصراً في الآخر

// مصفوفة ترابطية: كل قيمة لها اسم (مفتاح) بدل الرقم
$slide = [
    'title'    => 'مرحباً بكم',     // المفتاح => القيمة
    'subtitle' => 'في خدمة الطالب',
    'image'    => 'slider/slide-1.jpg',
];
echo $slide['title'];          // مرحباً بكم

// مصفوفة من المصفوفات: قائمة سجلات (مثل جدول له صفوف وأعمدة)
$slides = [
    ['title' => 'الأول', 'image' => 'a.jpg'],
    ['title' => 'الثاني', 'image' => 'b.jpg'],
];
echo $slides[1]['title'];      // الثاني
```

النوع الثالث هو الأهم لنا: كل قسم في صفحتنا **قائمة** من العناصر، وكل عنصر له **حقول** بأسماء (عنوان، صورة، تاريخ...).

## السلايدر من مصفوفة

أضف بيانات الشرائح بعد الدالة `e()` (بعد السطر 13 وقبل `?>`):

@stage home arr-slides

مصفوفة اسمها `$slider_images`، فيها ثلاث مصفوفات ترابطية، لكل واحدة ثلاثة مفاتيح: `title` و`subtitle` و`image` (مسار الصورة **داخل** `uploads`).

الآن **الحلقة**. الأمر `foreach` يمرّ على عناصر المصفوفة واحداً واحداً:

```php مثال
<?php foreach ($slider_images as $slide) {
    echo $slide['title'];      // يُنفَّذ 3 مرات، وفي كل مرة $slide عنصر مختلف
}

// مع رقم العنصر: $i = 0 ثم 1 ثم 2
foreach ($slider_images as $i => $slide) { ... }
```

وداخل HTML نستعمل **الصيغة البديلة** الأوضح: نقطتان `:` بدل `{`، و`endforeach;` بدل `}`. الآن استبدل كل كود السلايدر (من `<!-- السلايدر الرئيسي -->` إلى نهاية `</div>` الخاص به) بهذه النسخة:

@stage home slider-php

لم يتغيّر إلا موضعان:

- **الأسطر 850–852** (النقاط): بدل ثلاثة أسطر `<li>` مكتوبة يدوياً، سطر واحد داخل حلقة. `$i` رقم الشريحة نطبعه في `data-slide-to`. ثم **شرط**: `<?php if ($i == 0): ?>class="active"<?php endif; ?>`: إذا كان الرقم يساوي صفراً (الشريحة الأولى) اطبع `class="active"`. لاحظ أن `==` للمقارنة، و`=` للإسناد. خطأ شائع جداً أن تكتب `=` في الشرط!
- **الأسطر 857–865** (الشرائح): شكل الشريحة **مرة واحدة**: الصنف `active` للأولى فقط بنفس الشرط، والصورة `uploads/` متبوعة بمسارها من المصفوفة، والعنوان والجملة. وكل قيمة تمرّ عبر `e()`.

حدّث الصفحة: السلايدر كما كان بالضبط. افتح المصدر (Ctrl+U) وابحث عن `carousel-indicators`: ستجد ثلاثة أسطر `<li>` كتبتها PHP بنفسها!

## النتيجة

احفظ وحدّث الصفحة. يجب أن تكون **مطابقة** لما كانت عليه (مع خمسة أخبار في الصندوق بدل ثلاثة). أما الملف فصار أقصر بحوالي 50 سطراً رغم أننا أضفنا كل البيانات في أوله، والأهم: **البيانات منفصلة عن الشكل**. لتغيير محتوى الصفحة لم تعد تلمس HTML أبداً، بل تعدّل المصفوفات فقط.

| قبل (الفصول 5–9) | بعد (هذا الفصل) |
|---|---|
| كل خبر 19 سطراً من HTML | كل خبر 8 أسطر بيانات، والشكل مكتوب مرة واحدة |
| إضافة إقامة = نسخ 14 سطراً بدقة | إضافة إقامة = سطران في المصفوفة |
| خطأ في شكل البطاقة = إصلاحه 3 مرات | إصلاحه مرة واحدة داخل الحلقة |

::: warning
إذا ظهر تحذير `Undefined array key "titel"` فهناك اختلاف بين اسم المفتاح في المصفوفة واسمه في القالب (خطأ إملائي). وإذا ظهر `Undefined variable $slide` فأنت تستعمل المتغيّر خارج حلقته (بعد `endforeach`). وإذا توقفت الصفحة عند نقطة معيّنة فابحث عن `endforeach;` أو `endif;` منسي.
:::

::: summary
- المصفوفات: مرقّمة `[a, b]` وترابطية `['key' => value]`، وقائمة سجلات = مصفوفة من المصفوفات الترابطية.
- `foreach ($list as $i => $item): ... endforeach;` تكرّر الشكل لكل عنصر، و`if (...): ... endif;` تشرط ظهوره.
- `count()` و`array_slice()` و`$arr[] =` و`date()` مع `strtotime()`.
- الدالة `e()` تهرّب كل نص قبل طباعته (حماية من XSS).
- فصلنا البيانات (أعلى الملف) عن الشكل (HTML بحلقات).
:::
