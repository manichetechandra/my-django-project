# السلايدر وأول سطور JavaScript

::: intro
تحت شريط التنقل مباشرة يأتي **السلايدر**: صور كبيرة تتبدّل تلقائياً كل بضع ثوانٍ، وعلى كل صورة عنوان وجملة قصيرة. في هذا الفصل ننشئ مجلد الصور المرفوعة `uploads`، ونكتب السلايدر بمكوّن Bootstrap الجاهز، ونتعرّف على **JavaScript** و**jQuery** لنتحكم في سرعته.
:::

## مجلد الصور: uploads

صور السلايدر (وصور الأخبار والنشاطات والإقامات لاحقاً) ليست جزءاً ثابتاً من تصميم الموقع مثل الشعار، بل **محتوى** يتغيّر: المدير سيرفع صوراً جديدة من لوحة التحكم. لذلك نضعها في مجلد خاص اسمه `uploads` (أي «المرفوعات»)، منفصل عن `assets`.

1. أنشئ في جذر المشروع المجلد `uploads`، وداخله المجلد `slider`.
2. ضع فيه **ثلاث صور** عريضة (صور للجامعة أو الإقامات أو المطعم... أي صور لديك)، وسمّها: `slide-1.jpg` و`slide-2.jpg` و`slide-3.jpg`.

::: tip
أفضل مقاس لصور السلايدر حوالي **1600×600 بكسل** (عريضة)، وبحجم أقل من 300 كيلوبايت لكل صورة حتى تُحمَّل الصفحة بسرعة. إن كانت صورك من نوع آخر (`.png` مثلاً) فغيّر الامتداد في الكود بعد قليل ليطابق اسم ملفك.
:::

شجرة المشروع الآن:

```plaintext
dou-setif/
├── assets/
│   └── images/
│       └── logo.svg
├── uploads/
│   └── slider/
│       ├── slide-1.jpg
│       ├── slide-2.jpg
│       └── slide-3.jpg
└── index.html
```

## هيكل السلايدر في Bootstrap

السلايدر (carousel) مكوّن جاهز في Bootstrap: نحن نكتب فقط هيكل HTML بأصناف محددة، وBootstrap JS يتكفّل بالحركة. الهيكل العام:

```html مثال
<div id="myCarousel" class="carousel slide" data-ride="carousel">
    <ol class="carousel-indicators"> ... النقاط أسفل الصور ... </ol>
    <div class="carousel-inner">
        <div class="item active"> صورة + نص </div>   <!-- الشريحة الظاهرة أولاً -->
        <div class="item"> صورة + نص </div>
    </div>
    <a class="left carousel-control"> ‹ </a>      <!-- السهم السابق -->
    <a class="right carousel-control"> › </a>     <!-- السهم التالي -->
</div>
```

- **السطر 487**: الحاوية. `id="myCarousel"` معرّف نستعمله في الأسهم والنقاط وفي JavaScript. `carousel slide` سلايدر بحركة انزلاق. `data-ride="carousel"` تعني: ابدأ الحركة تلقائياً عند تحميل الصفحة.
- **الأسطر 489–493** المؤشّرات: نقطة لكل شريحة. `data-target` يحدّد السلايدر الذي تتحكم فيه، و`data-slide-to` رقم الشريحة التي تنتقل إليها عند النقر (يبدأ العدّ من **0** لا من 1). والنقطة الأولى `active` لأن الشريحة الأولى هي الظاهرة.
- **السطر 496** `carousel-inner`: الصندوق الذي يحمل الشرائح. `role="listbox"` معلومة لقارئات الشاشة.
- **الأسطر 497–503**: الشريحة الأولى، وصنفها `item active` (الظاهرة عند البداية). داخلها:
  - **السطر 498**: الصورة بمسار نسبي `uploads/slider/slide-1.jpg`، و`alt` يحمل عنوان الشريحة.
  - **الأسطر 499–502** `carousel-caption`: النص فوق الصورة: عنوان `<h3>` وجملة `<p>`.
- **الأسطر 504–517**: الشريحتان الثانية والثالثة بنفس الشكل تماماً، لكن صنفهما `item` فقط (بلا `active`).
- **الأسطر 520–528** الأسهم: رابطان بالصنفين `left carousel-control` و`right carousel-control`. `href="#myCarousel"` مع `data-slide="prev"` أو `"next"`: انتقل إلى الشريحة السابقة أو التالية. داخل كل سهم أيقونة من مكتبة **Glyphicons** المدمجة في Bootstrap 3 (`glyphicon-chevron-left`)، ونص مخفي لقارئات الشاشة.

::: note
لاحظ أن الشرائح الثلاث **متطابقة في الشكل**، لا يختلف إلا الصورة والنصّان. احفظ هذه الملاحظة: في الفصل 11 سنكتب شكل الشريحة **مرة واحدة** فقط، وPHP يكرّره لكل صورة.
:::

أولاً قواعد قلب السلايدر للعربية. أضفها في كتلة `<style>` العامة، **بعد** قاعدة التنبيهات `.alert` وقبل التعليق `/* Pagination RTL */`:

- **الأسطر 183–191**: في Bootstrap الأصلي السهم «السابق» على اليسار. في صفحة عربية نقرأ من اليمين، فنبدّل المكانين: `left` يلتصق باليمين (`right: 0; left: auto`)، و`right` يلتصق باليسار.
- **الأسطر 193–197**: نص الشريحة بهامش 15% من كل جانب ومحاذى لليمين.

ثانياً، الصفحة الرئيسية لها تنسيقات خاصة بها لا تحتاجها الصفحات الأخرى (السلايدر، بطاقات الأخبار...). نضعها في كتلة `<style>` **ثانية** داخل `<head>`، بعد الكتلة العامة مباشرة (بعد `</style>` في السطر 217). اكتب سطرها الأول:

## JavaScript: التحكم في السلايدر

السلايدر يعمل الآن بإعدادات Bootstrap الافتراضية (يتبدّل كل 5 ثوانٍ). لكن موقعنا يريد التحكم في سرعته وفي سلوكه عند مرور الفأرة، وهنا نحتاج **JavaScript**.

**JavaScript** لغة برمجة حقيقية تعمل **داخل المتصفح** (على عكس PHP التي سنراها لاحقاً وتعمل على الخادم). نستعملها لكل ما يتغيّر في الصفحة دون إعادة تحميلها: تحريك السلايدر، عدّاد الإحصائيات، فتح القوائم... ومكتبة **jQuery** (التي أضفناها في الفصل 3) تختصر كتابتها بالرمز `$`:

```javascript مثال
// تعليق في JavaScript يبدأ بشرطتين
var count = 0;                       // متغيّر اسمه count قيمته 0
$('#myCarousel')                     // اختر العنصر الذي id="myCarousel" (مثل محدِّدات CSS)
$('.alert').fadeOut();               // اختر كل .alert وأخفها تدريجياً
function sayHello() {                // دالة: مجموعة أوامر لها اسم
    alert('مرحباً!');                // نافذة رسالة
}
setInterval(sayHello, 4000);         // نفّذ الدالة كل 4000 ميلي ثانية (4 ثوانٍ)
```

الآن أضف هذا السكربت في **آخر** `<body>`، بعد سطر Bootstrap JS مباشرة:

@stage home home-js

- **السطر 538**: الوسم `<script>`: ما بعده JavaScript حتى `</script>`.
- **السطر 539** `$(document).ready(function() { ... });`: «عندما تكتمل قراءة الصفحة، نفّذ هذه الأوامر». نحتاجه لأن السكربت لا يجب أن يبحث عن العناصر قبل أن تكون موجودة. (وبما أننا وضعناه في آخر الصفحة فالعناصر موجودة أصلاً، لكنها عادة جيدة.)
- **الأسطر 541–544**: نختار السلايدر بمعرّفه، ونستدعي الدالة `carousel` التي يضيفها Bootstrap JS إلى jQuery، ونعطيها **كائناً** من الإعدادات بين قوسين معقوفين: `interval: 5000` الانتقال كل 5 ثوانٍ، و`pause: 'hover'` توقّف مؤقت عندما يمرّ الزائر بالفأرة فوق السلايدر ليقرأ النص.
- **الأسطر 546–550**: نفس الشيء لسلايدر **الإقامات** (معرّفه `media`) كل 4 ثوانٍ. هذا السلايدر غير موجود بعد في صفحتنا (سنبنيه في الفصل 8)، و jQuery لا يعترض: إذا لم يجد عنصراً لا يفعل شيئاً.
- **الأسطر 552–565**: حركة صندوق **آخر الأخبار** الذي سنبنيه في الفصل القادم:
  - **السطر 553**: `var newsItems` متغيّر يحمل كل عناصر الأخبار `.news-item` داخل `#latest-news-ticker`.
  - **السطر 554**: رقم الخبر الظاهر حالياً، يبدأ من 0.
  - **الأسطر 556–560**: دالة `showNextNews` تُخفي كل الأخبار (`hide`)، ثم تُظهر الخبر رقم `currentIndex` بحركة تلاشٍ (`eq` تختار عنصراً برقمه، و`fadeIn` تُظهره تدريجياً)، ثم تزيد الرقم. العامل `%` باقي القسمة: إذا كان لدينا 5 أخبار فبعد الخبر رقم 4 يصبح `(4 + 1) % 5 = 0`، فنعود إلى الأول. هكذا تدور الأخبار بلا نهاية.
  - **الأسطر 562–565**: `if` شرط: **إذا** كان عدد الأخبار أكبر من صفر، شغّل الدالة كل 4 ثوانٍ (`setInterval`)، واعرض الخبر الأول فوراً.

::: note
سنعود إلى السطرين 547 و553 عندما يظهر سلايدر الإقامات وصندوق الأخبار. كتبنا السكربت كاملاً الآن لأنه كتلة واحدة في الموقع النهائي (شارة «نهائي»: سيُنقل لاحقاً كما هو إلى قالب الصفحة الرئيسية).
:::

حدّث الصفحة وانتظر بضع ثوانٍ: تتبدّل الصور، وتتحرك النقطة البيضاء. جرّب الأسهم والنقاط، ومرّر الفأرة فوق الصورة لتتوقف الحركة.

3. افتح Console في أدوات المطوّر (F12) واكتب: `$('#myCarousel').carousel('next')` ثم Enter: تنتقل الشريحة!
:::

::: summary
- `uploads/` مجلد المحتوى المرفوع (يتغيّر)، و`assets/` مجلد ملفات التصميم الثابتة.
- السلايدر = `carousel` + `carousel-indicators` + `carousel-inner` فيه `item` (أولها `active`) + سهمان `carousel-control`.
- كتلة `<style>` ثانية في `<head>` خاصة بالصفحة الرئيسية، نضيف إليها قواعد كل قسم.
- JavaScript تعمل في المتصفح، وjQuery يختار العناصر بـ `$('محدِّد')`. `$(document).ready` و`setInterval` و`if` و`%` رأيناها في سكربت الصفحة.
:::
