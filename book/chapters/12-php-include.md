# تقسيم الصفحة إلى أجزاء: include

::: intro
كل صفحات الموقع ستحمل نفس شريط التنقل ونفس التذييل. بدل نسخهما في كل ملف، نضع كل جزء في **ملف مستقل**، وتستدعيه كل صفحة بسطر واحد بالأمر `include`. في هذا الفصل ننشئ أول مجلدات الهيكل النهائي للمشروع: `app/views/base`، ونضع فيه ملفي `navbar.php` و`footer.php`، والثاني يأخذ شكله **النهائي** من الآن (تبقى نصوصه فقط لنجعلها قابلة للترجمة لاحقاً).
:::

## الفكرة: include

الأمر `include` يقرأ ملف PHP آخر ويضع محتواه **في مكانه** كأنه مكتوب هناك:

```php مثال
<!-- page.php -->
<h1>صفحتي</h1>
<?php include 'part.php'; ?>
<p>بعد الجزء</p>
```

إذا كان في `part.php` السطر `<p>أنا الجزء المشترك</p>`، فالناتج في المتصفح:

```html مثال
<h1>صفحتي</h1>
<p>أنا الجزء المشترك</p>
<p>بعد الجزء</p>
```

وأربعة أوامر متشابهة:

| الأمر | إن لم يوجد الملف | إن ضُمِّن من قبل |
|---|---|---|
| `include` | تحذير، وتكمل الصفحة | يضمّنه مرة أخرى |
| `require` | **خطأ قاتل**، تتوقف الصفحة | يضمّنه مرة أخرى |
| `include_once` / `require_once` | مثل أعلاه | لا يضمّنه ثانية |

نستعمل `include` للأجزاء المرئية (إن غاب شريط التنقل تبقى الصفحة)، و`require` للملفات التي لا يعمل الموقع بدونها (الإعدادات، الدوال) كما سنرى.

::: note
الملف المضمَّن يرى كل **متغيرات** الملف الذي ضمّنه ودواله. فإذا عرّفنا `$current_year` في `index.php` ثم ضمّنا `footer.php`، يستطيع التذييل استعمالها. سنستفيد من هذا بعد قليل.
:::

المشروع النهائي ينظّم ملفاته في مجلد اسمه `app` (التطبيق)، وداخله مجلد `views` (العروض أو **القوالب**: ملفات HTML التي تعرض الصفحات)، وداخله مجلد `base` للأجزاء الأساسية المشتركة بين كل الصفحات. أنشئ هذه المجلدات الثلاثة الآن:

```plaintext
dou-setif/
├── app/
│   └── views/
│       └── base/
├── assets/
├── uploads/
└── index.php
```

## بقية قواعد PHP التي ستقرؤها في المشروع

صفحتنا لم تحتج حتى الآن إلا القليل من لغة PHP: المتغيرات، والمصفوفات، والدوال، و`foreach`، و`if` مع المقارنة `==`. أما كود المشروع النهائي، من الفصل 15 فصاعداً، فيستعمل قواعد أخرى في كل ملف تقريباً. نجمعها هنا مرة واحدة، فإذا قابلتها لاحقاً عرفتها. جرّب الأمثلة في ملف مؤقت `test.php` كما في الفصل 10، ثم احذفه. والدالة `var_dump` (الفصل 10) تعرض نوع القيمة مع القيمة، فهي الأنسب لهذه التجارب.

### المقارنة الصارمة: `===` و`!==`

```php مثال
<?php
var_dump(5 == '5');     // bool(true)
var_dump(5 === '5');    // bool(false)
var_dump(5 != 4);       // bool(true)
var_dump(5 !== '5');    // bool(true)
var_dump(0 == false);   // bool(true)
var_dump(0 === false);  // bool(false)
```

`==` متسامحة: تحوّل القيمتين إلى نوع واحد ثم تقارن، فالعدد 5 يساوي النص `'5'` (السطر 2). و`===` صارمة: تشترط النوع نفسه أيضاً، وهنا عدد ونص (السطر 3). و`!=` «لا يساوي» عكس `==`، و`!==` «لا يطابق» عكس `===`. في المشروع نستعمل `===` و`!==` في كل مكان تقريباً، لأن تسامح `==` يخدع أحياناً، كما في السطر 6: الصفر «يساوي» `false`! مثال حقيقي: `strpos($text, 'abc')` تُرجع **موضع** `abc` في النص (والموضع الأول رقمه 0)، أو `false` إن لم تجده. فالشرط `strpos(...) == false` يخطئ حين يكون `abc` في أول النص، والصحيح `strpos(...) === false`. وبقية المقارنات كما في الرياضيات: `<` و`>`، و`<=` (أصغر أو يساوي)، و`>=` (أكبر أو يساوي).

### الشروط المركّبة، و`elseif` و`else`

```php مثال
<?php
$score = 14;
$absent = false;

if ($score >= 10 && !$absent) {      // الشرطان معاً
    echo 'ناجح';
}
if ($score < 5 || $absent) {         // يكفي أحدهما
    echo 'راسب';
}

if ($score >= 16) {
    echo 'ممتاز';
} elseif ($score >= 10) {            // يُفحص فقط إن لم يصح ما قبله
    echo 'مقبول';
} else {                             // إن لم يصح شيء مما سبق
    echo 'غير مقبول';
}
```

`&&` تعني «و»: الشرطان معاً، و`||` تعني «أو»: يكفي أحدهما، و`!` قبل الشرط تعني «ليس»: تعكسه، فـ `!$absent` صحيحة لأن `$absent` خطأ. و`elseif` «وإلا إذا»، و`else` «وإلا». وPHP يتوقف عن الحساب متى عرف الجواب: في `$a && $b` إن كان `$a` خطأ فلا يُنظر في `$b` أصلاً، وفي `$a || $b` إن كان `$a` صحيحاً. لذلك ستقرأ شروطاً مثل `$user && $user['is_active']`: الجزء الثاني لا يُقرأ إن لم يوجد مستخدم، فلا تحذير. وفي القوالب الصيغة البديلة التي رأيتها في الفصل 11: `<?php elseif (...): ?>` و`<?php else: ?>`، ثم `<?php endif; ?>` في الآخر.

### الشرط في سطر واحد، والقيمة البديلة `??`

```php مثال
<?php
$count = 3;
echo $count > 1 ? 'أخبار' : 'خبر';      // أخبار

$news = ['title' => 'افتتاح المكتبة'];
echo $news['title'] ?? 'بلا عنوان';     // افتتاح المكتبة
echo $news['image'] ?? 'default.jpg';   // default.jpg
```

- `$c ? $a : $b`: إن صح الشرط `$c` فالنتيجة `$a`، وإلا `$b`. هي `if` و`else` في سطر واحد، تُستعمل حيث نحتاج **قيمة**.
- `$a ?? $b` («القيمة أو البديل»): `$a` إن كانت موجودة وليست `null`، وإلا `$b`. في المثال المفتاح `image` غير موجود، فطُبع البديل بلا أي تحذير. الفرق عن `?:` التي رأيناها قبل قليل: `?:` تختبر **الفراغ** (النص الفارغ والصفر يُستبدلان أيضاً)، لكنها تُظهر التحذير `Undefined array key` إن لم يوجد المفتاح، أما `??` فتختبر **الوجود** بلا تحذير. لذلك نقرأ بها كل ما قد لا يرسله الزائر.

### هل القيمة موجودة؟ `isset` و`empty` و`unset`

```php مثال
<?php
$news = ['title' => 'افتتاح المكتبة', 'image' => ''];
var_dump(isset($news['title']));  // bool(true)
var_dump(isset($news['views']));  // bool(false)
var_dump(empty($news['image']));  // bool(true)
var_dump(empty($news['views']));  // bool(true)
unset($news['image']);            // تحذف عنصراً من المصفوفة، أو متغيراً كاملاً
```

`isset` تسأل: هل المفتاح موجود وقيمته ليست `null`؟ و`empty` تسأل: هل القيمة فارغة؟ والمفتاح الغائب عندها فارغ أيضاً، بلا تحذير (السطر 6). و«الفارغ» عند `empty` ست قيم: النص الفارغ `''`، والصفر `0`، والنص `'0'`، و`null`، و`false`، والمصفوفة الفارغة `[]`. وهي نفسها القيم التي يعدّها `if` «خطأ»: `if ($list)` تعني «إن كانت المصفوفة غير فارغة».

### اختصارات، وتحويل الأنواع

```php مثال
<?php
$html = '<ul>';
$html .= '<li>سطيف</li>';   // تلصق في آخر النص
$total = 10;
$total += 5;                // 15
$total -= 3;                // 12
$total *= 2;                // 24
$i = 0;
$i++;                       // 1
$i--;                       // 0
echo 17 % 5;                // 2

var_dump((int) '42');       // int(42)
var_dump((float) '3.5');    // float(3.5)
var_dump((string) 2026);    // string(4) "2026"
var_dump((bool) '');        // bool(false)
```

- `$x .= $y` اختصار لـ `$x = $x . $y`، وكذلك `+=` و`-=` و`*=` مع الجمع والطرح والضرب. و`++` تزيد واحداً، و`--` تُنقص واحداً. و`%` باقي القسمة: 17 على 5 تساوي 3 والباقي 2.
- `(int)` و`(float)` و`(string)` و`(bool)` تحوّل القيمة إلى عدد صحيح، أو عشري، أو نص، أو قيمة منطقية (القيم الست «الفارغة» تصبح `false`). وستقرأ أيضاً `(array)`: تجعل القيمة مصفوفة إن لم تكن كذلك. ما يرسله الزائر يصلنا **نصوصاً** دائماً، حتى الأرقام (`?page=2` تصلنا `'2'`)، فنحوّله إلى النوع الذي نريده قبل استعماله.

### حلقات أخرى: `for` و`while`، و`break` و`continue`

```php مثال
<?php
for ($i = 1; $i <= 3; $i++) {       // البداية؛ شرط الاستمرار؛ ما يُنفَّذ بعد كل دورة
    echo $i . ' ';                  // 1 2 3
}

$n = 1;
while ($n < 100) {                  // كرّر ما دام الشرط صحيحاً
    $n *= 2;                        // 2 4 8 16 32 64 128
}

foreach ([5, 0, 8, -1, 3] as $x) {
    if ($x === 0) {
        continue;                   // اترك هذه الدورة وانتقل إلى التالية
    }
    if ($x < 0) {
        break;                      // اخرج من الحلقة كلها
    }
    echo $x . ' ';                  // 5 8
}
```

ولكل حلقة صيغة بديلة للقوالب كما لـ `foreach`: `for (...):` تنتهي بـ `endfor;`، و`while (...):` تنتهي بـ `endwhile;`.

### الاختيار بين حالات: `switch` و`match`

```php مثال
<?php
$type = 'sport';
switch ($type) {                    // قارن قيمة واحدة بعدة حالات
    case 'sport':
        echo 'رياضي';
        break;                      // بدونها يكمل التنفيذ في الحالة التالية!
    case 'culture':
        echo 'ثقافي';
        break;
    default:                        // إن لم تطابق أي حالة
        echo 'آخر';
}

echo match ($type) {                // أقصر، وتُرجع قيمة، ومقارنتها صارمة
    'sport'   => 'رياضي',
    'culture' => 'ثقافي',
    default   => 'آخر',
};
```

`match` (من PHP 8) تقارن بـ `===`، وتُرجع قيمة الحالة المطابقة مباشرة، فلا تحتاج `break`.

### الأنواع في الدوال، والخيارات المجمّعة

```php مثال
<?php
function greet(string $name, ?string $title = null): string
{
    return $title === null ? 'مرحباً ' . $name : 'مرحباً ' . $title . ' ' . $name;
}

function log_line(string $text): void
{
    file_put_contents('log.txt', $text . "\n", FILE_APPEND | LOCK_EX);
}

echo greet('أحمد');                // مرحباً أحمد
echo greet('أحمد', 'الأستاذ');      // مرحباً الأستاذ أحمد
```

- `string $name`: المعامل يجب أن يكون نصاً. و`?string`: نص **أو** `null`. و`= null` قيمة افتراضية، فيمكن ترك المعامل عند الاستدعاء كما في الاستدعاء الأول.
- `: string` بعد القوسين نوع القيمة التي تُرجعها الدالة، و`: void` تعني أنها لا تُرجع شيئاً.
- الأنواع اختيارية في PHP، لكنها توثّق الدالة وتكشف الأخطاء: لو مررنا مصفوفة مكان النص لتوقف PHP برسالة واضحة.
- `FILE_APPEND | LOCK_EX`: بعض الدوال تقبل عدة **خيارات** في معامل واحد، فنجمع ثوابتها بالعلامة `|` («هذا وذاك»). هنا: أضف في آخر الملف، واقفله أثناء الكتابة. سنشرح `file_put_contents` في الفصل 17.

| العامل | معناه |
|---|---|
| `===` و`!==` | يطابق، لا يطابق: القيمة والنوع معاً |
| `==` و`!=` | يساوي، لا يساوي: بعد تحويل النوع |
| `&&` و`\|\|` و`!` | و، أو، ليس |
| `$c ? $a : $b` | `$a` إن صح `$c`، وإلا `$b` |
| `$a ?: $b` | `$a` إن لم تكن فارغة، وإلا `$b` |
| `$a ?? $b` | `$a` إن وُجدت وليست `null`، وإلا `$b` |
| `.=` و`+=` و`++` | ألصق في الآخر، أضف، زد واحداً |
| `(int)` و`(string)` و`(bool)` | تحويل النوع |

::: summary
- `include` و`require` يضعان محتوى ملف آخر في مكانهما، والملف المضمَّن يرى متغيرات من ضمّنه.
- `__DIR__` مسار مجلد الملف الحالي: يجعل مسارات التضمين صحيحة دائماً.
- أنشأنا `app/views/base` ونقلنا إليه `navbar.php` (تنسيقه نهائي) و`footer.php` (شكله نهائي).
- `?:` تعطي قيمة بديلة إذا كانت الأولى فارغة.
- بقية قواعد اللغة التي سنقرؤها في كل ملف: المقارنة الصارمة `===`، والشروط المركّبة، و`??` و`isset` و`empty`، والاختصارات وتحويل الأنواع، وحلقات `for` و`while`، و`switch`، والأنواع في الدوال.
:::
